# June 10 No-Go Surface Map

## Rule

If a screen, module, county, data path, or workflow is not runtime-proven through TerraFusion DB/API, it must be labeled, hidden, blocked, or excluded from the June 10 demo.

## Do Not Open During Demo

- CMA surfaces that return empty reports or unsupported comparable sets.
- Regression Studio if placeholder or fixture-backed.
- VEI if placeholder or not sourced.
- PACS Bridge if it implies live Hostinger PACS connectivity.
- TerraLevy if sample data appears live.
- Management dashboards with hardcoded statistics.
- Elite operational surfaces with fabricated metrics.
- AI valuation outputs that return hardcoded value, confidence, or comps.
- TerraFusion Sync product surfaces that imply generalized production readiness.
- Any non-Benton runtime operation without county-specific TerraFusion DB/API proof.

## Allowed If Truthfully Labeled

- Preview surfaces.
- Onboarding surfaces.
- Provenance inventory surfaces.
- County Data Intake MVP surfaces.
- Unavailable states.
- Not Runtime Enabled states.

## Non-Benton County Rule

Non-Benton counties may show:

- County identity.
- Role context.
- Source posture.
- Readiness status.
- Provenance inventory.
- Governed intake posture.

Non-Benton counties must not show:

- Official runtime parcel operations.
- Certified valuation workflows.
- Production-ready assessment workflows.
- Live county operations unless county-specific TerraFusion DB/API proof exists.

## Benton Rule

Benton may show runtime pilot surfaces where evidence supports the data and workflow. Benton PACS source lineage may be discussed only as provenance. The runtime path remains TerraFusion DB/API.
