## 🔄 For Developers

### If you need to work on AI features:

1. **Clone the new repository:**
   ```bash
   git clone https://github.com/bsvalues/terrafusion-ai-platform.git
   ```

2. **Review the documentation:**
   - Repository README: https://github.com/bsvalues/terrafusion-ai-platform#readme
   - Migration Guide: [POLYREPO_MIGRATION_GUIDE.md](../../POLYREPO_MIGRATION_GUIDE.md)
   - Quick Reference: [POLYREPO_QUICK_REFERENCE.md](../../POLYREPO_QUICK_REFERENCE.md)

3. **Set up dependencies:**
   ```bash
   cd terrafusion-ai-platform
   pip install -r requirements.txt  # Python-based
   ```

4. **Start development:**
   ```bash
   python -m terrafusion_ai  # or your platform's dev command
   ```
