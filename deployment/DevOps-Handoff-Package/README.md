## 🚀 QUICK START FOR DEVOPS

```bash
# 1. Clone the DevOps package
git clone git@github.com:Terrafusion-Enterprise/DevOps-Handoff-Package.git
cd DevOps-Handoff-Package

# 2. Run the environment setup
./scripts/setup-devops-environment.sh

# 3. Configure your IDE
./tools/ide-setup/configure-vscode.sh

# 4. Start local development environment
./environments/development/start-local-env.sh

# 5. Verify everything is working
./scripts/validate-devops-setup.sh
```
