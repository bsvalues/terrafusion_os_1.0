# TERRAFUSION DEPLOYMENT COMMANDS
# Execute these on your server or hosting provider

# 1. UPLOAD THE PACKAGE
# Using SCP (replace with your server details):
scp terrafusion-web-ready.tar.gz user@terrafusionmarket.io:/home/user/

# Or using FTP/cPanel:
# Upload terrafusion-web-ready.tar.gz to your hosting account

# 2. ON THE SERVER (via SSH):
cd /var/www/terrafusionmarket.io/public_html
# Or your web root directory

# 3. BACKUP EXISTING (if any):
mv index.html index.html.backup 2>/dev/null

# 4. EXTRACT DEPLOYMENT:
tar -xzf ~/terrafusion-web-ready.tar.gz

# 5. SET PERMISSIONS:
chmod 644 index.html .htaccess
chmod 755 assets/
chmod 644 assets/*

# 6. VERIFY DEPLOYMENT:
curl -I https://terrafusionmarket.io

# 7. TEST FUNCTIONALITY:
# Open in browser: https://terrafusionmarket.io
# Verify all 14 apps display
# Check system metrics update
# Test control panel

# ALTERNATIVE: Using hosting control panel
# 1. Login to your hosting control panel (cPanel/Plesk/etc)
# 2. Navigate to File Manager
# 3. Upload terrafusion-web-ready.tar.gz
# 4. Extract in public_html or www directory
# 5. Verify .htaccess support is enabled
