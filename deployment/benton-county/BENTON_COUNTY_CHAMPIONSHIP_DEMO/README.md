## 🚀 Demo Deployment

### Quick Start
```bash
# Clone the demo package
git clone <demo-repository>
cd BENTON_COUNTY_CHAMPIONSHIP_DEMO

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env with your configuration

# Start the demo
npm run demo:start

# Access the demo
# Web Interface: http://localhost:3000
# API Documentation: http://localhost:3000/api-docs
# Marketplace: http://localhost:3001
```

### Demo Scripts
```bash
# Start full demo environment
npm run demo:full

# Start specific tier
npm run demo:tier1
npm run demo:tier2
npm run demo:tier3

# Run demo scenarios
npm run demo:scenario:property-assessment
npm run demo:scenario:tax-calculation
npm run demo:scenario:workflow-automation
npm run demo:scenario:ai-analysis

# Health check
npm run demo:health
```
