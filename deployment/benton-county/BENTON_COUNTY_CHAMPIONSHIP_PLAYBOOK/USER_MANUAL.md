### Query Types and Routing

#### 🔒 **RED Queries** (Local Processing)

These contain sensitive information and stay on your local system:

- Owner names and contact information
- Social Security Numbers
- Tax records and financial details
- Personal property information

**Example**: "Who owns the property at 456 Pine Street?" **Route**: 🔒 Local
Ollama → **Privacy Protected**

#### 🟡 **YELLOW Queries** (Anonymized Cloud)

These mix sensitive data with calculations:

- Property analysis with addresses
- Market comparisons with specific locations
- Investment calculations for named properties

**Example**: "Compare 123 Main St value to neighborhood average" **Route**: 🔒
Anonymize → ☁️ Cloud → **Secure & Accurate**

#### 🟢 **GREEN Queries** (Cloud Processing)

Pure calculations and general information:

- Mathematical calculations
- Market trend analysis
- General property questions
- ROI and financial modeling

**Example**: "Calculate ROI for $300k property with $2k rent" **Route**: ☁️
Cloud → **Fast & Powerful**

## 🛠️ TROUBLESHOOTING

### Common Issues and Solutions

#### 🚨 **"System Not Responding"**

**Symptoms**: Dashboard won't load, queries fail **Solutions**:

1. Check if dynasty is running: `./LAUNCH_DYNASTY.sh status`
2. Restart system: `./LAUNCH_DYNASTY.sh restart`
3. Check logs: `./LAUNCH_DYNASTY.sh logs`

#### 🚨 **"Slow Response Times"**

**Symptoms**: Queries taking >200ms, poor performance **Solutions**:

1. Trigger evolution: Click **🧬 Trigger Evolution**
2. Check system resources: Click **🏥 Health Check**
3. Restart Ollama: `ollama serve`

#### 🚨 **"Ollama Connection Failed"**

**Symptoms**: All queries fail, local routing unavailable **Solutions**:

1. Check Ollama status: `ollama list`
2. Restart Ollama: Kill process and restart
3. Reinstall if needed: `curl -fsSL https://ollama.ai/install.sh | sh`

#### 🚨 **"High Memory Usage"**

**Symptoms**: System slow, memory alerts in logs **Solutions**:

1. Reduce concurrent models: `export OLLAMA_MAX_LOADED_MODELS=1`
2. Clear query cache: Restart system
3. Check for memory leaks in logs

#### 🚨 **"API Key Errors"**

**Symptoms**: Cloud queries fail, authentication errors **Solutions**:

1. Check .env file has valid API keys
2. Verify key permissions and limits
3. Rotate keys if necessary
