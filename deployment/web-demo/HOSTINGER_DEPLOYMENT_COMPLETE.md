## 🌐 **DEPLOYMENT TO HOSTINGER - 5 MINUTE PROCESS**

### Step 1: Access Hostinger File Manager

1. Log into your Hostinger account
2. Go to **Hosting** → **Manage**
3. Click **File Manager**
4. Navigate to your domain's **public_html** folder

### Step 2: Upload Files (Drag & Drop)

1. Open the `hostinger-package/public_html/` folder on your computer
2. **Select ALL files** (Ctrl+A or Cmd+A)
3. **Drag and drop** everything into Hostinger's public_html folder
4. Wait for upload to complete (~30MB total)

### Step 3: Set Permissions (If Needed)

- Most files should work automatically
- If you get permission errors, set:
  - Folders: **755**
  - PHP files: **644**
  - Database: **644**

### Step 4: Test Your Demo

- Visit: **https://yourdomain.com**
- Test API: **https://yourdomain.com/api/?request=health**

## 🆘 **TROUBLESHOOTING**

### **Demo not loading?**

1. Check all files uploaded to public_html/
2. Verify .htaccess file is present
3. Test API directly: /api/?request=health

### **Database errors?**

1. Ensure benton-county-demo.db is in data/ folder
2. Check file permissions (644)
3. Verify PHP has SQLite support (standard on Hostinger)

### **API not working?**

1. Test health endpoint: /api/?request=health
2. Check .htaccess URL rewriting
3. Verify PHP version is 7.4+

### **Slow performance?**

1. Enable caching in Hostinger control panel
2. Check database file size (~27MB is normal)
3. Monitor resource usage
