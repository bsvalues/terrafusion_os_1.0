### Data Integration Points

The model will integrate with multiple data sources:

1. **Land Classification Database**: Connect to Benton County GIS to extract current land use classifications
2. **Property Valuation API**: Pull market rates for comparable properties from County Assessor 
3. **Tax Rate Tables**: Import annual tax tables for all relevant districts
4. **Federal Payment Records**: Track Department of Education payments to school districts

### Annual Calculation Workflow

The model will implement this annual cycle:

1. **January**: Import updated land classification and property valuation data
2. **February**: Obtain current year tax rates from all districts
3. **March**: Calculate preliminary payment projections
4. **April**: Generate formal certification documentation for DOE review
5. **May**: Finalize payment requests and distribution plans
6. **October-December**: Reconcile actual payments against projections

### Payment Distribution Algorithm

The distribution formula follows this sequence:

```python
def calculate_payment_distribution(self, year):
    # 1. Calculate base land values by classification
    land_values = self.calculate_classified_land_values()
    
    # 2. Apply district-specific tax rates
    gross_taxes = {}
    for district in self.districts:
        gross_taxes[district] = 0
        for land_type in land_values:
            value = land_values[land_type][district]
            rate = self.tax_rates[district][land_type]
            gross_taxes[district] += value * rate
    
    # 3. Apply federal offsets for education payments
    net_taxes = gross_taxes.copy()
    for district in ['Richland', 'Kiona-Benton']:
        if district in self.federal_offsets:
            net_taxes[district] -= self.federal_offsets[district]
    
    # 4. Calculate pro-rata allocation for partial payments
    available_funding = self.get_available_funding(year)
    if available_funding < sum(net_taxes.values()):
        funding_ratio = available_funding / sum(net_taxes.values())
        for district in net_taxes:
            net_taxes[district] *= funding_ratio
    
    return net_taxes
```

```jsx
const ExecutiveSummaryCard = ({ historyData, distributionData }) => {
  const currentYear = new Date().getFullYear();
  const currentYearData = historyData.find(d => d.Year === currentYear);
  const previousYearData = historyData.find(d => d.Year === currentYear - 1);
  
  // Calculate year-over-year change
  const yoyChange = previousYearData ? 
    ((currentYearData?.Amount - previousYearData.Amount) / previousYearData.Amount) * 100 : 0;
  
  return (
    <Card className="shadow-md rounded-2xl">
      <CardHeader>
        <h2 className="text-xl font-bold">PILT Summary {currentYear}</h2>
      </CardHeader>
      <CardContent>
        <div className="grid grid-cols-2 gap-4">
          <div>
            <p className="text-sm text-muted-foreground">Total PILT Received</p>
            <p className="text-3xl font-bold">${currentYearData?.Amount.toLocaleString()}</p>
            <Badge variant={yoyChange >= 0 ? "success" : "destructive"}>
              {yoyChange >= 0 ? "+" : ""}{yoyChange.toFixed(1)}% from previous year
            </Badge>
          </div>
          <div>
            <p className="text-sm text-muted-foreground">Top Recipient</p>
            <p className="text-xl font-bold">
              {distributionData.sort((a, b) => b.Amount - a.Amount)[0]?.District}
            </p>
            <p className="text-sm">
              {(distributionData.sort((a, b) => b.Amount - a.Amount)[0]?.Amount /

            </p>
          </div>
        </div>
      </CardContent>
    </Card>
  );
};
```

#### 4. Interactive GIS Map Overlay

```jsx
const PILTMapOverlay = ({ parcelData, distributionData }) => {
  const mapRef = useRef(null);
  
  useEffect(() => {
    if (!mapRef.current || !parcelData?.features?.length) return;
    
    // Initialize map
    const map = new maplibregl.Map({
      container: mapRef.current,
      style: 'https://demotiles.maplibre.org/style.json',
      center: [-119.3345, 46.2503], // Benton County approximate center
      zoom: 9
    });
    
    map.on('load', () => {
      // Add parcel layer
      map.addSource('parcels', {
        type: 'geojson',
        data: parcelData
      });
      
      // Join distribution data with parcel geometries
      const maxAmount = Math.max(...distributionData.map(d => d.Amount));
      
      map.addLayer({
        id: 'pilt-parcels',
        type: 'fill',
        source: 'parcels',
        paint: {
          'fill-color': [
            'match',
            ['get', 'district'],
            ...distributionData.flatMap(d => [
              d.District,
              // Color intensity based on relative amount
              ['interpolate', ['linear'], ['/', ['get', 'amount'], maxAmount],
                0, '#f1f5f9',
                0.25, '#94a3b8',
                0.5, '#64748b',
                0.75, '#334155',
                1, '#0f172a'
              ]
            ]),
            '#f1f5f9' // default color
          ],
          'fill-opacity': 0.7,
          'fill-outline-color': '#000000'
        }
      });
      
      // Add hover interactions
      map.addLayer({
        id: 'pilt-parcels-highlighted',
        type: 'fill',
        source: 'parcels',
        paint: {
          'fill-color': '#10b981',
          'fill-opacity': 0.9
        },
        filter: ['==', 'district', '']
      });
      
      // Show tooltip on hover
      map.on('mousemove', 'pilt-parcels', (e) => {
        if (e.features.length === 0) return;
        
        const feature = e.features[0];
        map.setFilter('pilt-parcels-highlighted', ['==', 'district', feature.properties.district]);
        
        const districtData = distributionData.find(d => d.District === feature.properties.district);
        if (!districtData) return;
        
        const popup = new maplibregl.Popup()
          .setLngLat(e.lngLat)
          .setHTML(`
            <h3 class="font-bold">${feature.properties.district}</h3>
            <p>PILT Amount: $${districtData.Amount.toLocaleString()}</p>
            <p>Land Area: ${feature.properties.acres.toLocaleString()} acres</p>
          `)
          .addTo(map);
      });
    });
    
    return () => map.remove();
  }, [parcelData, distributionData]);
  
  return (
    <Card className="shadow-md rounded-2xl">
      <CardHeader>
        <h2 className="text-xl font-bold">PILT Geographic Distribution</h2>
      </CardHeader>
      <CardContent style={{ height: 500 }}>
        <div ref={mapRef} className="w-full h-full rounded-md overflow-hidden" />
      </CardContent>
    </Card>
  );
};
```
