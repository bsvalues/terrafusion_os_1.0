## 🚀 Deployment Instructions

### Prerequisites

- Node.js 18+ and npm
- MySQL/PostgreSQL database
- Hostinger hosting account
- Domain name (terrafusionmarket.io)

### Quick Deployment

```bash
# 1. Clone and prepare
git clone [repository]
cd modules/shock-and-awe

# 2. Install dependencies
npm install
cd server && npm install && cd ..

# 3. Configure deployment
./deploy.sh check                    # Run pre-deployment checks
./deploy.sh deploy                   # Full production deployment

# 4. Verify deployment
curl https://terrafusionmarket.io/health
```

### Configuration

Edit `deploy.config` with your Hostinger settings:

```bash
DOMAIN="terrafusionmarket.io"
FTP_HOST="your-ftp-host"
FTP_USER="your-username"
FTP_PASSWORD="your-password"
DB_HOST="localhost"
DB_NAME="terrafusion_market"
```
