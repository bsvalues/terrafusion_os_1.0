## 🎯 STEP-BY-STEP DRAG & DROP DEPLOYMENT

### STEP 1: Login to Hostinger
1. Go to [hostinger.com](https://hostinger.com)
2. **Login** to your account
3. Go to **Control Panel**

### STEP 2: Open File Manager
1. Find your domain: **terrafusionmarket.io**
2. Click **"Manage"** or **"File Manager"**
3. Navigate to **"public_html"** folder

### STEP 3: Drag & Drop Upload
1. **Locate** the file: `terrafusion-deployment.tar.gz`
2. **Drag** the file into the File Manager
3. **Drop** it into the `public_html` folder
4. Wait for upload to complete (should be fast - only 42KB!)

### STEP 4: Extract the Archive
1. **Right-click** on `terrafusion-deployment.tar.gz`
2. Select **"Extract"** or **"Unzip"**
3. Choose **"Extract to current directory"**
4. **Delete** the .tar.gz file after extraction (optional)

### STEP 5: Verify Files
You should now see these files in `public_html`:
```
✅ index.html
✅ manifest.json
✅ sw.js
✅ robots.txt
✅ sitemap.xml
✅ .htaccess
✅ 404.html
✅ 500.html
✅ styles/ (folder with CSS files)
✅ js/ (folder with JavaScript files)
```

### STEP 6: Go Live!
1. **Visit:** https://terrafusionmarket.io
2. **Test the demo:** https://terrafusionmarket.io/#demo
3. **Check mobile:** Open on your phone

## 🚨 TROUBLESHOOTING

### If Site Doesn't Load:
1. **Wait 5-10 minutes** - DNS might need to propagate
2. **Clear Browser Cache** - Hard refresh (Ctrl+Shift+R)
3. **Check File Structure** - Ensure index.html is in public_html root
4. **Verify .htaccess** - File should be visible in File Manager

### If Demo Doesn't Work:
1. **Check JavaScript Console** - Press F12 → Console tab
2. **Verify JS Files** - Ensure js/ folder has all 4 JavaScript files
3. **Test Different Browser** - Try Chrome, Firefox, Safari
4. **Mobile Test** - Sometimes works better on mobile

### Common File Manager Issues:
1. **Upload Failed** - File might be too large (but 42KB should be fine)
2. **Extract Failed** - Try uploading individual files instead
3. **Permissions** - Files should be 644, folders 755 (usually automatic)
