## 🛠️ MCP Tools Available

### 1. **process_permit_application**
Process permit applications with consciousness-aware algorithms and quantum optimization.

**Parameters:**
- `permit_type`: Type of permit (building, business, environmental, etc.)
- `applicant_name`: Name of permit applicant
- `description`: Project/activity description
- `location`: Permit location/address
- `county`: County name (optional)
- `business_name`: Business name if applicable (optional)
- `special_requirements`: Additional requirements (optional)
- `consciousness_enhancement`: Enable MIT PhD enhancements (default: true)

### 2. **track_permit_status**
Track permit status using consciousness-aware workflow monitoring with predictive analytics.

**Parameters:**
- `permit_id`: Permit ID to track (format: TFP-YYYYMMDD-XXXXXXXX)
- `include_workflow_details`: Include detailed workflow stages (default: true)
- `consciousness_enhancement`: Enable MIT PhD enhancements (default: true)

### 3. **generate_permit_analytics**
Generate comprehensive permit analytics with predictive modeling and consciousness insights.

**Parameters:**
- `county`: County name for analytics
- `analysis_period_days`: Analysis period in days (30-365, default: 90)
- `include_predictions`: Include predictive analytics (default: true)  
- `consciousness_enhancement`: Enable MIT PhD enhancements (default: true)

### 4. **get_consciousness_metrics**
Get current consciousness awareness metrics and permit system status.

**Parameters:** None required
