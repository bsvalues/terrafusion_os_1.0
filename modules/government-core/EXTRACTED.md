## 🔄 For Developers

### If you need to work on government features:

1. **Clone the new repository:**
   ```bash
   git clone https://github.com/bsvalues/terrafusion-government-platform.git
   ```

2. **Review the documentation:**
   - Repository README: https://github.com/bsvalues/terrafusion-government-platform#readme
   - Migration Guide: [POLYREPO_MIGRATION_GUIDE.md](../../POLYREPO_MIGRATION_GUIDE.md)
   - Quick Reference: [POLYREPO_QUICK_REFERENCE.md](../../POLYREPO_QUICK_REFERENCE.md)

3. **Set up dependencies:**
   ```bash
   cd terrafusion-government-platform
   npm install  # or yarn install, or pip install -r requirements.txt
   ```

4. **Start development:**
   ```bash
   npm run dev  # or your platform's dev command
   ```
