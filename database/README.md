## Quick Start

### Database Operations

```bash
# Initialize database systems
npm run database:init --multi-database

# Run schema migrations
npm run database:migrate --zero-downtime

# Seed production data
npm run database:seed --production

# Validate database health
npm run database:health --comprehensive
```

### Harris PACS Integration

```bash
# Sync Benton County parcels
npm run harris-pacs:sync --county=benton --parcels=89247

# Validate Harris PACS integration
npm run harris-pacs:validate --production

# Monitor synchronization
npm run harris-pacs:monitor --real-time
```


