Step 1: React Component
────────────────────────
File: frontend/src/components/ide/TaskRunner.tsx
Code: Click handler in button
  onClick={() => handleRunTask(task)}

Step 2: API Call
────────────────
Code: Inside handleRunTask()
  const response = await axios.post('/api/tasks/run', {
    task_id: 'build',
    module_id: 'default'
  })

Note: URL is '/api/tasks/run' (RELATIVE PATH)

Step 3: Vite Proxy
────────────────
File: frontend/vite.config.ts
Config:
  proxy: {
    '/api': {
      target: 'http://localhost:8787',
      changeOrigin: true
    }
  }

What happens:
  Request to '/api/tasks/run' → Intercepted by Vite
  Forwarded to 'http://localhost:8787/api/tasks/run'

Step 4: Backend Receives Request
─────────────────────────────────
File: backend/src/main.rs
Route: .route("/api/tasks/run", post(run_task_handler))

Handler: async fn run_task_handler(Json(request): Json<RunTaskRequest>)

Step 5: Backend Processes
──────────────────────────
Service: task_runner_service::TaskRunnerService
Action: Validates task, creates execution
Returns: JSON response with status + execution_id

Step 6: Response Sent to Frontend
──────────────────────────────────
JSON Response:
{
  "status": "started",
  "execution": {
    "execution_id": "xyz-123",
    "task_id": "build",
    "module_id": "default",
    "created_at": "2025-10-17T..."
  }
}

Step 7: React Processes Response
─────────────────────────────────
Code in handleRunTask():
  const result = {
    success: response.data.status === 'started',
    output: response.data.execution_id || 'Task started'
  }
  setResults(prev => ({ ...prev, [task.id]: result }))

Step 8: UI Updates
──────────────────
Button changes to ✅ or ❌
Output panel displays result
Task state updates
User sees real backend response

TOTAL TIME: ~200-500ms
