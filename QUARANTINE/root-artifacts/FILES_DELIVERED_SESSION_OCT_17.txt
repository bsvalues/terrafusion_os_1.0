HOW INTEGRATION WORKS (The Magic)
───────────────────────────────────────────────────────────────────────────────

File Flow When User Clicks Button:

TaskRunner.tsx (Frontend)
  └─→ axios.post('/api/tasks/run', {...})
      └─→ HTTP POST request created
          └─→ Vite intercepts (vite.config.ts proxy)
              └─→ Routed to http://localhost:8787/api/tasks/run
                  └─→ Rust backend receives
                      └─→ run_task_handler() executes
                          └─→ task_runner_service processes
                              └─→ Response created
                                  └─→ JSON returned
                                      └─→ Vite relays back to React
                                          └─→ TaskRunner.tsx receives
                                              └─→ setResults() called
                                                  └─→ UI updates
                                                      └─→ User sees result

Total latency: ~200-500ms
