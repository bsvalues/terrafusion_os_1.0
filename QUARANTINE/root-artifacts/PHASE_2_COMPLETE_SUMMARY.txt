================================================================================
                         COMPONENT DETAILS
================================================================================

1. FileExplorer.tsx
   ────────────────
   - Recursive file tree with expand/collapse icons
   - Search filter for quick navigation
   - Icons for files (📄) vs directories (📁)
   - Click to select files for editing
   - Calls: GET /api/files/list

2. CodeEditor.tsx
   ───────────────
   - Large textarea for code editing
   - Language detection from file extension
   - Save button (appears when unsaved)
   - Copy button (copy all code)
   - Line counter on left
   - Monospace font (Courier New)
   - Calls: POST /api/files/read, POST /api/files/write

3. Terminal.tsx
   ─────────────
   - WebSocket connection to backend terminal
   - Real-time command output streaming
   - Green text for input, red for errors, gray for output
   - Connection status indicator (green/red dot)
   - Minimize/restore functionality
   - Command history
   - Calls: ws://localhost:8787/api/terminal/ws

4. AICopilot.tsx
   ──────────────
   - Chat interface with 1,008-agent swarm
   - Agent level selection:
     * Beginner: Basic help
     * Advanced: Full-featured AI
     * Ninja: Full swarm with all capabilities
   - Code context integration (selectedCode)
   - Typing indicator: "✨ Thinking..."
   - Message history with timestamps
   - Calls: POST /api/ai/ask

5. TaskRunner.tsx
   ───────────────
   - 6 predefined tasks:
     * Build: cargo build
     * Test: cargo test
     * Lint: cargo clippy
     * Format: cargo fmt
     * Deploy: ./deploy.sh
     * Dev: npm run dev
   - Real-time status (running, success ✓, failed ✗)
   - Expandable output display
   - Task history with counts
   - Calls: POST /api/tasks/{id}/run, POST /api/tasks/{id}/stop

6. IDELayout.tsx
   ──────────────
   - Master composition component
   - Renders all 5 components in VS Code-like layout
   - Handles state passing between components
   - Responsive design with Tailwind
   - Dark theme (gray-900, gray-800 palette)
   - Collapsible panels (show/hide buttons)
