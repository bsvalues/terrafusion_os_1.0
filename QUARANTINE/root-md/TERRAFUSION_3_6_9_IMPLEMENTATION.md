```

├─ Stream 1: Core government deliverable
├─ Stream 2: County validation/testing
└─ Stream 3: Government documentation

Never block on county dependencies within a phase.
Front-load government blockers, parallelize county work.
```

### **2. Government 3-Question Diagnostic**
```
Before every government decision:
1. Do I have county data? (Evidence check)
2. Have I considered county alternatives? (Options check)
3. Can I defend this to citizens? (Rationale check)

If 3/3 yes → Government approved
If 2/3 yes → Research county needs more
If 1/3 yes → Escalate to state level
```

