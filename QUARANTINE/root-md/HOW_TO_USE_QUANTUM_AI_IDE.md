## 🛠️ **TROUBLESHOOTING**

### **If Extension Doesn't Load**
1. Check VS Code version: Requires 1.80.0+
2. Verify TerraFusion project detection:
   - Look for `terrafusion.config.json`
   - Check `config/core-os.toml`
3. Restart VS Code after installation

### **If Commands Don't Appear**
1. Open Command Palette: `Ctrl+Shift+P`
2. Type "TerraFusion" to see all commands
3. Check Activity Bar for "TerraFusion Quantum AI" panel

### **If Dashboard Doesn't Open**
1. Check browser compatibility (WebGL required)
2. Verify port 3000 availability
3. Check backend services are running
