## 📚 API Documentation

### REST API Endpoints

**AI Code Assistant** (`/api/ai/code-assistant`):
- `POST /complete` - Get code completions
- `POST /cell-suggestions` - Get next cell suggestions
- `POST /predict-errors` - Predict code errors

**AI Optimization** (`/api/ai/optimize`):
- `POST /` - Get optimization suggestions
- `POST /analyze` - Analyze code quality

**AI Debugging** (`/api/ai/debug`):
- `POST /analyze` - Comprehensive debug analysis
- `POST /suggestions` - Get debug suggestions
- `POST /inspect` - Inspect variables
- `POST /paths` - Predict execution paths
- `POST /breakpoints` - Analyze breakpoints

**Performance Profiling** (`/api/ai/profile`):
- `POST /` - Profile code execution
- `POST /bottlenecks` - Detect bottlenecks
- `POST /recommendations` - Get optimization recommendations
- `POST /metrics` - Calculate metrics

**Documentation** (`/api/ai/docs`):
- `POST /` - Generate documentation
- `POST /docstring` - Generate docstring
- `POST /readme` - Generate README
- `POST /analyze` - Analyze module

**Visualization** (`/api/ai/visualize`):
- `POST /` - Generate visualization
- `GET /recommendations` - Get chart recommendations

### SignalR Hubs

**NotebookHub** (`/hubs/notebook`):
- `ExecuteCell(cellId, code, language)` - Execute code
- `CancelExecution(cellId)` - Cancel execution
- `GetExecutionStatus(cellId)` - Get status

**CollaborationHub** (`/hubs/collaboration`):
- `JoinSession(sessionId, user)` - Join session
- `SyncChanges(sessionId, version, operations)` - Sync content
- `UpdateCursor(sessionId, userId, position)` - Update cursor
- `UpdateSelection(sessionId, userId, selection)` - Update selection

**AnalyticsHub** (`/hubs/analytics`):
- `SubscribeToMetrics(metricType)` - Subscribe to metrics
- `GetRealtimeMetrics()` - Get current metrics

**WorkflowHub** (`/hubs/workflow`):
- `StartWorkflow(workflowId)` - Start workflow
- `GetWorkflowStatus(workflowId)` - Get status
