## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+ installed
- npm package manager
- Modern web browser

### Installation & Setup
```bash
# 1. Navigate to demo directory
cd BENTON_COUNTY_CHAMPIONSHIP_DEMO

# 2. Install dependencies
npm install

# 3. Run demo setup
npm run demo:setup

# 4. Start the demo server
npm run demo:start

# 5. Open in browser
# Web Interface: http://localhost:3000
# API Documentation: http://localhost:3000/api-docs
```

### Demo Scripts
```bash
# Start full demo environment
npm run demo:full

# Start specific tier
npm run demo:tier1
npm run demo:tier2
npm run demo:tier3

# Run demo scenarios
npm run demo:scenario:property-assessment
npm run demo:scenario:tax-calculation
npm run demo:scenario:workflow-automation
npm run demo:scenario:ai-analysis

# Health check
npm run demo:health
```
