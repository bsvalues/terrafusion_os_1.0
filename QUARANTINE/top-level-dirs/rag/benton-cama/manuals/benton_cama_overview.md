# Benton County CAMA Overview

## Computer Assisted Mass Appraisal (CAMA) System

Benton County, Washington utilizes the Harris Govern PACS system for property assessment and valuation management. This document provides an overview of the CAMA processes specific to Benton County.

## County Information

- **County**: Benton County, Washington
- **County Seat**: Prosser
- **Population**: Approximately 210,000
- **Total Parcels**: ~95,000 properties
- **Assessment Year**: Annual revaluation cycle

## CAMA System Components

### 1. Property Database
The CAMA system maintains comprehensive records for all parcels including:
- Legal descriptions and parcel identifiers
- Property characteristics (land and improvements)
- Sales transaction history
- Assessment history and values
- Ownership information

### 2. Valuation Models
Benton County uses the following valuation approaches:
- **Cost Approach**: Based on replacement cost less depreciation
- **Sales Comparison Approach**: Market-derived adjustments from comparable sales
- **Income Approach**: For commercial/income-producing properties

### 3. Quality Control
- Ratio studies performed annually
- Statistical analysis ensures assessment equity
- Appeals process available to property owners

## Assessment Calendar

| Month | Activity |
|-------|----------|
| January | Assessment roll opens |
| April 30 | Value change notices mailed |
| May-June | Informal review period |
| July 1 | Board of Equalization appeals deadline |
| October | Final values certified |

## Property Classifications

### Residential Property
- Single-family residences
- Multi-family (2-4 units)
- Condominiums
- Manufactured homes on owned land

### Commercial Property
- Retail buildings
- Office buildings
- Industrial facilities
- Warehouses

### Agricultural Property
- Farm and agricultural land
- Current use / Open space programs
- Timber land classifications
