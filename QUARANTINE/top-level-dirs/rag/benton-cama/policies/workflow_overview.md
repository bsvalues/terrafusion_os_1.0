# Benton County Assessment Workflow Overview

## Daily Operations Workflow

This document describes the standard workflow procedures for the Benton County Assessor's Office assessment operations.

---

## 1. Data Entry Workflow

### 1.1 New Parcel Creation
```
Step 1: Receive legal description from County Auditor
Step 2: Create parcel in Harris PACS
Step 3: Enter legal description and ownership
Step 4: Assign tax code area (TCA)
Step 5: Schedule property inspection
Step 6: Quality review by supervisor
```

### 1.2 Property Characteristic Updates
```
Step 1: Field appraiser completes inspection
Step 2: Data entered into PACS within 48 hours
Step 3: Sketches uploaded to document management
Step 4: Photos attached to parcel record
Step 5: Supervisor review (10% sample)
Step 6: Statistical analysis of changes
```

## 2. Sales Validation Process

### 2.1 Daily Sales Processing
All recorded sales are processed through a validation workflow:

| Status Code | Description | Action Required |
|-------------|-------------|-----------------|
| U | Unvalidated | Needs review |
| V | Valid Arms-Length | Use for valuation |
| I | Invalid | Exclude from analysis |
| P | Partial Interest | Adjust or exclude |
| F | Family Transfer | Exclude |
| B | Bank/REO Sale | Review for market |
| A | Auction Sale | Review for market |

### 2.2 Validation Steps
1. Review deed for transaction type
2. Verify buyer/seller relationship
3. Check for financing terms affecting price
4. Inspect property if needed
5. Compare to market trends
6. Document decision rationale

## 3. Valuation Cycle

### 3.1 Annual Revaluation Timeline

| Month | Activity | Responsible Party |
|-------|----------|-------------------|
| September | Model calibration begins | Valuation Team |
| October | Residential models completed | Senior Appraiser |
| November | Commercial models completed | Commercial Team |
| December | Land studies finalized | Land Analyst |
| January | Mass update processing | IT/Systems |
| February | Quality control reviews | Supervisors |
| March | Value change notices prepared | Admin Staff |
| April 30 | Notices mailed | Admin Staff |
| May-June | Informal review period | All Appraisers |
| July | BOE hearings begin | Appeals Team |

### 3.2 Model Development Process
```
1. Sales ratio analysis (prior year)
2. Market trend identification
3. Neighborhood delineation review
4. Adjustment factor development
5. Model testing and refinement
6. Supervisory approval
7. Documentation in working papers
```

## 4. Appeals Handling

### 4.1 Informal Review Process
- **Timeline**: 30 days from notice date
- **Method**: Phone, email, or in-person meeting
- **Documentation**: All contacts logged in PACS
- **Authority**: Appraiser can adjust up to 10% without supervisor approval

### 4.2 Board of Equalization (BOE)
- **Filing Deadline**: July 1 or 30 days from notice
- **Hearing Format**: 15-minute presentation
- **Evidence Required**: 
  - Recent comparable sales
  - Independent appraisal (optional)
  - Photos of condition issues
  - Cost documentation for improvements
- **Decision Timeline**: 30 days from hearing

## 5. Permit Processing

### 5.1 Building Permit Workflow
```
Permit Issued (Building Dept)
    ↓
Daily import to PACS
    ↓
Assignment to appraiser (by area)
    ↓
Inspection scheduled
    ↓
Inspection completed → Data entry
    ↓
Partial assessment (if applicable)
    ↓
Final assessment (upon completion)
```

### 5.2 Permit Types and Triggers
| Permit Type | Assessment Impact | Inspection Required |
|-------------|-------------------|---------------------|
| New Construction | Add value | Yes - multiple |
| Addition | Adjust value | Yes |
| Remodel | Review value | Conditional |
| Demolition | Remove value | Yes - verify |
| Mechanical | Generally none | No |
| Electrical | Generally none | No |

## 6. Quality Assurance

### 6.1 Daily QA Checks
- Random sample review (5% of entries)
- Outlier value detection
- Duplicate parcel check
- Missing data alerts

### 6.2 Monthly Statistics
- Sales ratio by property type
- Inspection completion rate
- Permit turnaround time
- Appeal success rate

### 6.3 Annual Audit Preparation
- IAAO ratio study standards
- Department of Revenue compliance
- Statistical benchmarks documentation
- Working papers organization
