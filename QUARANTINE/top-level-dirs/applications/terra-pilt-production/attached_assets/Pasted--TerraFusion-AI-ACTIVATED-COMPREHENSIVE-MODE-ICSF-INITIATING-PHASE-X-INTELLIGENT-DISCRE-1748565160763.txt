## 🧬 CLASSIFICATION ENGINE LOGIC

| Type            | Trigger Condition             | Reason Code          | Suggested Action                           |
| --------------- | ----------------------------- | -------------------- | ------------------------------------------ |
| Overpayment     | actual > expected + threshold | `OVERPAYMENT`        | "Verify assessed value or overfunded"      |
| Underpayment    | actual < expected - threshold | `UNDERPAYMENT`       | "Check levy rate or contact DOE"           |
| Rounding Error  | delta < \$2                   | `ROUNDING`           | "Acceptable discrepancy — review optional" |

| Rate Mismatch   | rate off by > 5%              | `RATE_DEVIATION`     | "Cross-check current levy for year"        |
| Historical Drop | >15% drop vs prior year       | `HISTORICAL_ANOMALY` | "Investigate structural changes"           |
