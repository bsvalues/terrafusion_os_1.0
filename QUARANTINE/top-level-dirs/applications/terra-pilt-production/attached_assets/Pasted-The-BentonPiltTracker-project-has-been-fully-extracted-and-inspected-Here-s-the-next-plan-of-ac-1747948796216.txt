### 🛠 LOCAL DEPLOYMENT STRATEGY (COUNTY NETWORK)

**🔹 Target Format**: `.exe` installer (via Inno Setup)

**🔹 Steps:**

1. **Build the Frontend (React/Vite assumed):**

   ```bash
   npm install
   npm run build
   ```

2. **Bundle Outputs into `dist/`**
   Ensure everything including:

   * `index.html`
   * `data/*.csv`
   * `assets/*`

3. **Inno Setup Script Template** (`installer.iss`)

   ```ini
   [Setup]
   AppName=Benton County PILT Dashboard
   AppVersion=1.0
   DefaultDirName={autopf}\PILT-Dashboard
   OutputDir=.\dist
   OutputBaseFilename=PILTInstaller
   DisableDirPage=yes
   DisableProgramGroupPage=yes
   PrivilegesRequired=admin
   SolidCompression=yes
   WizardStyle=modern
   SilentInstall=Yes

   [Files]
   Source: "dist\*"; DestDir: "{app}"; Flags: recursesubdirs createallsubdirs

   [Icons]
   Name: "{autodesktop}\PILT Dashboard"; Filename: "{app}\index.html"

   [Run]
   Filename: "{app}\index.html"; Description: "Open PILT Dashboard"; Flags: nowait postinstall skipifsilent
   ```

4. **Compile with Inno Setup Compiler**

   * Output: `PILTInstaller.exe`
   * Silent, self-contained executable
   * Ideal for SharePoint delivery or USB handoff
