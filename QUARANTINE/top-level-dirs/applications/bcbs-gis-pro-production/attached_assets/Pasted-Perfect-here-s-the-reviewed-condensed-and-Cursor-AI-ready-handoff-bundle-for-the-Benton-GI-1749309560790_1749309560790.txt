## 🧩 LLM Runtime Options

### Option 1: **LM Studio**

* Run from `C:\GISAssistant\lmstudio\`
* Enable local API server (default port `11434`)
* Load model like: `mistral-7b-instruct.Q4_K_M.gguf`

### Option 2: **Ollama (Optional/Approved)**

* Can import `.ollama` model archive (no internet required)
* Run via:

  ```bash
  ollama run mistral
  ```

## 🌐 Backend Server (Node.js)

### `/backend/server.js`

```js
const express = require('express');
const bodyParser = require('body-parser');
const { askLLM } = require('./lib/ai-client');
const app = express();
app.use(bodyParser.json());

app.post('/ask', async (req, res) => {
  const { prompt } = req.body;
  const reply = await askLLM(prompt);
  res.json({ reply });
});

app.listen(3001, () => console.log('GIS Assistant running on port 3001'));
```
