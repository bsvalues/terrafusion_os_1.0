## 🚀 Quick Start

### Prerequisites

- Docker (v20.10+)
- Docker Compose (v2.0+)
- OpenSSL (for SSL certificate generation)

### Installation

1. **Clone the repository:**
   \`\`\`bash
   git clone https://github.com/your-org/terrafusion-pro-1.git
   cd terrafusion-pro-1
   \`\`\`

2. **Configure environment:**
   \`\`\`bash
   cp .env.example .env
   # Edit .env with your specific configuration
   \`\`\`

3. **Deploy with one command:**
   \`\`\`bash
   bash scripts/deploy.sh
   \`\`\`

### Advanced Deployment Options

- **Clean deployment:** `bash scripts/deploy.sh --clean`
- **No-cache build:** `bash scripts/deploy.sh --no-cache`
- **Production mode:** Set `NODE_ENV=production` in `.env`
