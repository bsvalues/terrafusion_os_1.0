Cartographic Brand Guidelines

✓ Professional Standards

  • ✓ Maintain authentic cartographic contour line standards following USGS mapping conventions
  • ✓ Use varying line weights: major contours (1.8-2.2px), index contours (1.2-1.5px), intermediate (0.6-1.0px)
  • ✓ Preserve elevation markers, spot heights, and benchmark triangulation points in detailed applications
  • ✓ Apply depression contours with proper hachure marks for geographic accuracy
  • ✓ Ensure ridge and valley formations follow natural terrain flow patterns
  • ✓ Use the circular variant for app icons while maintaining contour line integrity
  • ✓ Implement subtle grid references at 15% opacity for professional surveying context

✗ Avoid These Practices

  • ✗ Never simplify contour lines to basic geometric shapes—maintain organic terrain flow
  • ✗ Don't use uniform line weights for all contour elements—professional maps require hierarchy
  • ✗ Avoid removing elevation markers or spot heights from detailed logo applications
  • ✗ Never create contour patterns that don't follow logical elevation progression
  • ✗ Don't apply arbitrary colors to different contour elements outside the brand palette
  • ✗ Avoid placing the logo on backgrounds that interfere with fine cartographic detail visibility
  • ✗ Never recreate cartographic elements without understanding proper surveying conventions
