## 🚀 **IMMEDIATE USAGE**

### **Quick Start (Choose Your Platform):**

#### **Windows:**
```cmd
cd ai-workspace-companion
quick-start.bat
```

#### **Unix/Linux/macOS:**
```bash
cd ai-workspace-companion
chmod +x quick-start.sh
./quick-start.sh
```

#### **Manual Launch:**
```bash
cd ai-workspace-companion
npm install
npm run companion
```

### **From Main Workspace:**
```bash
# Launch companion agent
npm run companion

# Development mode (verbose)
npm run companion:dev

# Quiet mode (minimal output)
npm run companion:quiet

# Check status
npm run companion:status

# Show help
npm run companion:help
```
