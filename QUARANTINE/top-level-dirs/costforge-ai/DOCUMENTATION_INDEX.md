## 🚀 Quick Reference

### Launch Commands

```bash
# Elite Quantum System (Recommended)
cd api
python terrafusion-elite-launcher.py

# Legacy Cost API
cd api
python costforge_api_server.py
```

### Key Endpoints

**Elite Quantum** (Port 8008):
- `GET /api/costforge/status` - System health
- `GET /api/costforge/valuation-demo` - Demo valuation
- `POST /api/costforge/valuate` - Single property

**Legacy Cost** (Port 5000):
- `GET /api/health` - Health check
- `POST /api/construction-costs` - Cost estimation
- `POST /api/batch-assessment` - Batch processing

### Configuration

```bash
# Environment Variables
export COSTFORGE_QUANTUM_FACTOR=949      # 949 or 999
export COSTFORGE_TARGET_ACCURACY=0.995   # 99.5%
export COSTFORGE_ELITE_MODE=true
export COSTFORGE_API_PORT=8008
```
