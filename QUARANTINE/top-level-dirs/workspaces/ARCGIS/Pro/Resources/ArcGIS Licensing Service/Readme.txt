The ArcGIS Licensing Service setup installs 64-bit Flex Net services.  ArcGIS Licensing Service is required  for a per-user installation to work offline with a Concurrent Use license or utilize Single Use licensing.

To install the ArcGIS Licensing Service run the ArcGISLS.msi setup file and follow the prompts.  Administrator privileges are required to run this setup.

A per-machine ("All users") installation automatically installs these Flex Net services.  The ArcGIS Licensing setup is only necessary to support per-user installations.
