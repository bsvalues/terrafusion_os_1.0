### **System 6: Biometric Responsiveness**
**Purpose:** Detect user pace and adjust animation tempo

**Tracking Mechanism:**
```

    ↓

    ↓
All GSAP animations scaled by tempo factor
    ↓
UI "breathes" with user interaction speed
```

**Tempo Range:**
- Idle (0.0 px/ms): 1.0x (normal speed)
