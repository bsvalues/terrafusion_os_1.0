# Fallback Plan

**Rule**: The conference must not depend on internet, database, or live AI.

---

## Fallback Tiers

### Tier 1 — Live Demo (Primary)
- Full running application
- Real-time search, dossier generation, codex navigation
- Requirements: laptop, local server running, no internet needed

### Tier 2 — Cached Demo (If server fails)
- Pre-rendered HTML pages with real data
- All routes work but data is static
- Requirements: laptop, browser only

### Tier 3 — PDF Package (If laptop fails)
- Printed/tablet PDF versions of all demo screens
- 3 PDFs: Atlas Dossier, County Pulse, Academy Codex
- Requirements: tablet or printed copies

### Tier 4 — Verbal + Screenshots (Absolute last resort)
- Screenshot deck on phone
- Talk through the story without live demo
- Requirements: phone or memory

---

## Fallback Materials Checklist

- [ ] Atlas Property Dossier PDF (polished, print-ready)
- [ ] County Pulse PDF (polished, print-ready)
- [ ] Academy Codex PDF (10 entries, print-ready)
- [ ] Screenshot deck (all key screens, 1920x1080)
- [ ] Pre-rendered HTML cache (all demo routes)
- [ ] Local data fixtures (JSON, no database dependency)
- [ ] 3-minute script (memorized, not read)
- [ ] 10-minute script (memorized, not read)

---

## Transition Triggers

| Signal | Action |
|---|---|
| Server won't start | Switch to Tier 2 (cached HTML) |
| Browser crashes | Switch to Tier 3 (PDFs on tablet) |
| Laptop dies | Switch to Tier 4 (phone screenshots) |
| Audience asks to see something unbuilt | "Great question — that's in our next release" |
| Demo data looks wrong | Skip to next section, don't debug live |

---

## Pre-Conference Checklist

- [ ] Run full demo on airplane mode
- [ ] Run full demo on venue WiFi (if available)
- [ ] Charge all devices to 100%

- [ ] Load screenshots on phone
- [ ] Practice 3-minute script 3 times
- [ ] Practice 10-minute script 2 times
