### 🚀 MCP Tools

#### 1. `search_public_records`

Search public records using consciousness-aware algorithms with quantum
optimization and corruption analysis.

**Parameters:**

- `query` (required): Search query for public records
- `record_types`: Types of records to search (permits, financial, legal,
  personnel, property, public_safety, meeting)
- `county`: County to filter search results
- `date_range`: Date range for record search
- `include_corruption_analysis`: Include corruption risk analysis (default:
  true)
- `consciousness_enhancement`: Enable MIT PhD consciousness enhancements
  (default: true)

**Example:**

```json
{
  "query": "building permits downtown",
  "record_types": ["permits", "financial"],
  "county": "Benton County",
  "include_corruption_analysis": true,
  "consciousness_enhancement": true
}
```

#### 2. `analyze_corruption_patterns`

Analyze corruption patterns using consciousness-aware detection algorithms with
predictive modeling.

**Parameters:**

- `department`: Department to focus analysis on (Finance, Public Works, Legal,
  etc.)
- `county`: County to analyze for corruption patterns
- `analysis_period_days`: Period in days for corruption analysis (default: 365)
- `risk_threshold`: Risk threshold for corruption detection (default: 0.6)

**Example:**

```json
{
  "department": "Finance",
  "county": "Benton County",
  "analysis_period_days": 365,
  "risk_threshold": 0.6
}
```

#### 3. `generate_transparency_report`

Generate comprehensive transparency reports with predictive governance
analytics.

**Parameters:**

- `county` (required): County name for transparency report
- `report_type`: Type of report (comprehensive, financial, compliance,
  corruption, performance)
- `include_predictions`: Include predictive governance analysis (default: true)
- `consciousness_enhancement`: Enable MIT PhD consciousness enhancements
  (default: true)

**Example:**

```json
{
  "county": "Benton County",
  "report_type": "comprehensive",
  "include_predictions": true,
  "consciousness_enhancement": true
}
```

#### 4. `get_consciousness_metrics`

Get current consciousness awareness metrics and championship system status.

**Parameters:** None
