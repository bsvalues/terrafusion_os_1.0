# AI Agent Instructions

This folder contains all protocols, operational instructions, and deployment
strategies for AI agents and subagent swarms within the TerraFusion Master
Workspace.

## Contents

- `master-agent-protocols.md`: Master agent protocols and governance
- `subagent-swarm-build.md`: Subagent swarm build and deployment instructions
  (Claude Code, etc.)
- `deployment-strategies.md`: Agent deployment and monitoring strategies
- `agent-roles.md`: Definitions of agent and subagent roles
- `historical-protocols/`: Archive of all previous protocols and experiments
- `INDEX.md`: Canonical index of all protocol documents
- `CHANGELOG.md`: Protocol update history and audit trail

**Purpose:**

- Ensure all AI agent intelligence and operational protocols are versioned,
  discoverable, and easy to update
- Enable rapid deployment and scaling of agent-based systems
- Support onboarding, governance, and future automation

---

## How to Propose Protocol Changes

1. **Review the [INDEX.md](./INDEX.md) and existing protocols** to avoid
   duplication or fragmentation.
2. **Edit or add protocol documents** as needed, following the established
   formats for clarity and completeness.
3. **Document your changes in [CHANGELOG.md](./CHANGELOG.md)** with a dated
   entry summarizing the update and affected files.
4. **Submit a pull request** with a clear rationale for your changes and
   reference any related issues or architectural decisions.
5. **Tag reviewers** with expertise in AI agent operations or governance for
   peer review.

> _Legendary clarity, traceability, and operational excellence are required for
> all protocol contributions._
