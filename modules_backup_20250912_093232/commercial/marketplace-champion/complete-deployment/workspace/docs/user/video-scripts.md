## Tutorial 2: Creating Your First Workflow (15 minutes)

### Script: Workflow Automation Made Simple

**[Scene 1: Introduction - 0:00-0:45]**

**Narrator**: "Workflow automation is at the heart of Terrafusion's efficiency
gains. In this tutorial, you'll create your first automated workflow - a
document approval process that will save hours of manual work."

**[Scene 2: Accessing Workflow Builder - 0:45-2:00]**

- Navigate to Services menu
- Click Workflow Builder
- Explain interface

**Narrator**: "From your dashboard, navigate to Services and select Workflow
Builder. This visual tool lets you create powerful automations without any
coding. On the left, you'll find workflow components. The center canvas is where
you'll build your workflow. The right panel shows properties and settings."

**[Scene 3: Creating New Workflow - 2:00-4:00]**

- Click Create New
- Name workflow
- Add description

**Narrator**: "Click 'Create New Workflow'. Give it a descriptive name - let's
call it 'Document Approval Process'. Add a clear description so others
understand its purpose. Select your department and choose 'Document Management'
as the category."

**[Scene 4: Adding Trigger - 4:00-6:00]**

- Drag trigger component
- Configure trigger
- Explain options

**Narrator**: "Every workflow starts with a trigger. Drag the 'Form Submission'
trigger onto the canvas. This workflow will start when someone submits a
document for approval. Configure the trigger by selecting 'Document Approval
Form' from the dropdown. You can also set conditions - for example, only trigger
for documents over a certain value."

**[Scene 5: Building the Flow - 6:00-10:00]**

- Add approval step
- Configure routing
- Add conditions

**Narrator**: "Now let's add the approval logic. Drag an 'Approval' component
and connect it to the trigger. Configure it to route to the appropriate manager
based on document type.

Add a 'Condition' component to create different paths. For example, if approved,
route to 'Send Notification' and 'Update Database'. If rejected, route to
'Notify Submitter' with feedback.

Let's add email notifications. Drag 'Send Email' components for both paths.
Configure the approved email with a success message and next steps. For
rejections, include the reason and how to resubmit."

**[Scene 6: Advanced Features - 10:00-12:00]**

- Show parallel processing
- Add error handling
- Explain monitoring

**Narrator**: "Terrafusion workflows support advanced features. Add parallel
processing to notify multiple people simultaneously. Include error handling to
manage exceptions gracefully. The monitoring dashboard lets you track workflow
performance and identify bottlenecks."

**[Scene 7: Testing - 12:00-14:00]**

- Use test mode
- Submit test document
- Review execution

**Narrator**: "Before going live, always test your workflow. Click 'Test Mode'
and submit a sample document. Watch as it flows through each step. Check the
execution log for any issues. Make adjustments as needed."

**[Scene 8: Activation - 14:00-15:00]**

- Save workflow
- Activate
- Share with team

**Narrator**: "Once tested, save your workflow and click 'Activate'. It's now
live and ready to use. Share the submission form link with your team.
Congratulations - you've just automated your first process with Terrafusion!"

## Quick Tips Series (2-minute videos)

### 1. Using the AI Assistant

**Narrator**: "Meet your AI assistant - always ready to help! Click the AI icon
in the bottom right. Try natural language commands like 'Show me pending
approvals' or 'Create a new expense report'. The AI learns from your usage
patterns, becoming more helpful over time. It can answer questions about the
platform, help navigate features, and even suggest workflow improvements."

### 2. Mobile App Features

**Narrator**: "Stay productive on the go with Terrafusion mobile! Download from
your app store and log in with your credentials. Approve documents with a swipe,
receive push notifications for urgent items, and access your dashboards
anywhere. The app works offline too - changes sync when you reconnect. Perfect
for field work or remote offices."

### 3. Integration Magic

**Narrator**: "Connect Terrafusion with your existing tools! Navigate to
Settings, then Integrations. Connect your email to automatically create tasks
from important messages. Sync with your calendar to track deadlines. Link cloud
storage for seamless document access. Each integration includes step-by-step
setup guides. Transform Terrafusion into your central operations hub!"

### 4. Security Best Practices

**Narrator**: "Keep your Terrafusion account secure! Use a unique, strong
password and never share it. Enable two-factor authentication - it takes seconds
but adds powerful protection. Be cautious of phishing emails - Terrafusion will
never ask for your password via email. Lock your screen when stepping away.
Report any suspicious activity immediately. Your security is our priority!"

### 5. Keyboard Shortcuts

**Narrator**: "Work faster with keyboard shortcuts! Press '?' anywhere in
Terrafusion to see available shortcuts. 'Ctrl+K' opens quick search. 'N' creates
a new item in any section. 'G' then 'D' goes to dashboard. 'G' then 'W' jumps to
workflows. Master these shortcuts to navigate Terrafusion at lightning speed!"

## Production Notes

### Visual Style

- Clean, modern interface shots
- Smooth transitions between scenes
- Highlight important elements with subtle animations
- Use Terrafusion brand colors consistently

### Audio Guidelines

- Professional narrator with clear, friendly tone
- Background music: subtle, professional
- Sound effects for clicks and transitions
- Ensure good audio levels throughout

### Recording Tips

- Use high-resolution screen recording (minimum 1080p)
- Hide personal information in demos
- Use consistent demo data
- Keep mouse movements smooth and deliberate

### Post-Production

- Add captions for accessibility
- Include chapter markers for easy navigation
- Export in multiple formats (YouTube, internal training)
- Create thumbnail images for each video
