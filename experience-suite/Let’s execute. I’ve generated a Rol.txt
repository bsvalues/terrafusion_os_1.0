# 10-minute “get it done” path

## 0) Prep

```
# in your workstation shell
export REPO_ROOT=/path/to/your/terrafusion/repo
export SUITE_DIR=~/Downloads/suite-v4/experience-suite-v4  # unzip v4 first
```

## 1) Overlay v4 into your repo (no file clobbering)

```
unzip experience-suite-v4.zip -d ~/Downloads/suite-v4
unzip rollout-kit-v4.zip -d ~/Downloads/rollout-kit
cd ~/Downloads/rollout-kit
./apply-v4.sh
```

This uses rsync `--ignore-existing` so it won’t overwrite your local changes.

## 2) Configure secrets/env

```
export ROUTE53_ZONE_ID=Zxxxxxxxxxxxx
export CDN_DOMAIN=media.terrafusion.gov
export KONG_API_HOST=api.terrafusion.gov
export APP_HOST=app.terrafusion.gov
export DATABASE_URL=postgres://user:pass@host:5432/terrafusion_prod
export TF_VAR_region=us-west-2
```

(For Azure AD / Okta frontends, set the variables from `.env.terrafusion.example` inside your UI build env.)

## 3) Bootstrap infra → app → flags → DB → checks

```
./bootstrap-v4.sh
```

It will:

* Terraform **CloudFront via Kong** (or skip if already provisioned),
* Terraform **EKS root** (optional; skips if folder not present),
* Helm deploy **Kong** and the **umbrella chart** (UI + API + ServiceMonitor),
* Instruct you to `deck sync` CSP & OIDC (one line each),
* Seed **Consul flags**,
* Run **DB migrations** (telemetry + flag\_audit),
* Run **brand scan**, **axe** test stub, and **smoke** on the live host.

## 4) Apply Kong decK (CSP + choose your OIDC)

```
deck sync -s kong.csp.yml
# choose Azure AD or Okta:
deck sync -s sso-extensions/kong/kong.oidc.azuread.yml
# or
deck sync -s sso-extensions/kong/kong.oidc.okta.yml
```

## 5) Verify brand/perf/a11y gates

* ESLint **brand rule** (no raw colors) must be clean.
* **Playwright** tiered visual snapshots T0–T4 pass.
* **Lighthouse** budgets + **FMF ≤ 1200 ms**.
* **axe**: zero critical issues.
* Grafana shows **tier mix** & **flag flip annotations**.
