## Wire-up (straight to production readiness)

### 1) CloudFront (Kong origin)

```bash
cd infra/cloudfront
terraform apply -var "region=us-west-2" \
  -var "origin_host=api.terrafusion.gov" \
  -var "origin_path=/media"
```

### 2) Consul flags (no extra SaaS)

```bash
consul kv import @ops/consul/seed-transcendence-flags.hcl
# Get/Set via API:
# GET  /api/flags/transcendence
# POST /api/flags/transcendence  { "key":"max_tier", "value":3, "actor":"ops", "reason":"brownout" }
```

Register `FeatureFlagService` and `FeatureFlagsController` in DI/startup.

### 3) Security: CSP + VIOLATION reporting

* Keep CSP in gateway or app; point `report-uri` (or `report-to`) at `/api/security/csp-report`.
* Add the included controller to capture violations into logs (or wire to SIEM).

### 4) Route preloads

Mount after router in your shell:

```tsx
import { RoutePreloads } from '@/preload/RoutePreloads';
<RoutePreloads route={location.pathname} />
```

This reads `scenes.ts` and preloads the right media (poster/video) for sub-1200ms first motion frame.

### 5) Workerized WebGL

You already have the OffscreenCanvas pipeline from the prior kit. Where available, prefer the workerized layer; otherwise fallback to the main-thread `WebGLLayer`. Tie in the **GPU tier cap**:

```ts
import { capTierByGPU } from '@/transcendence/capabilities.tiercap';
const capped = capTierByGPU(autoTier, capabilities.gpu);
```

### 6) Observability & Exec telemetry

* Run `ops/db/telemetry.sql` (from earlier kit).
* Start `startWebVitals()` at app bootstrap to emit `webvitals_lcp` and `webvitals_cls` alongside `ux_tier_selected`.
* Exec tiles can now show **tier mix by route**, and you can correlate with LCP/CLS.

### 7) Performance gates in CI

Add the workflow and tools directory. Gates:

* **Lighthouse** budgets: FCP ≤ 1200ms, LCP ≤ 2500ms, CLS ≤ 0.02
* **FPS**: Playwright check ≥ 55 on `/` and `/dashboard`
