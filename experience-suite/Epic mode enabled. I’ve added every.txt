## 2) Terraform “One Stack” (CloudFront + ACM + Route53 + Kong origin)

* `infra/stack/main.tf`

  * **ACM cert** (us-east-1) for `cdn_domain`
  * **CloudFront** distribution with **Kong** origin (`kong_api_host`) and `origin_path=/media`

# Fast track: exact steps

### A) Verify the bundle

```bash
# Pick one:
unzip experience-suite-v3.zip -d ./suite-v3
# or
tar -xzf experience-suite-v3.tar.gz -C ./suite-v3

cd suite-v3/experience-suite-v3
./verify-suite.sh
```

### B) Deploy the infra (Terraform)

Set these GitHub Secrets in your repo:

* `ROUTE53_ZONE_ID`, `CDN_DOMAIN` (e.g., `media.terrafusion.gov`), `KONG_API_HOST` (`api.terrafusion.gov`)
* optionally `WAF_WEB_ACL_ARN`

Run the **Deploy Infra** workflow (`.github/workflows/deploy-infra.yml`). It will:

* issue an ACM cert (us-east-1),
* stand up CloudFront with Kong origin,
* create Route53 alias records.

### C) Deploy the app (Helm)

Set these secrets:

* `KUBECONFIG_CONTENT` (base64 or plaintext kubeconfig content),
* `UI_IMAGE`, `API_IMAGE`, `APP_HOST` (e.g., `app.terrafusion.gov`)

Run **Deploy App** (`.github/workflows/deploy-app.yml`).

### D) SSO on the frontend

Choose Azure **or** Okta:

* **Azure:** set `VITE_AZURE_AD_CLIENT_ID`, `VITE_AZURE_AD_TENANT_ID`, `VITE_AUTH_REDIRECT_URI`
* **Okta:** set `VITE_OKTA_ISSUER`, `VITE_OKTA_CLIENT_ID`, `VITE_AUTH_REDIRECT_URI`

Mount the provider + guard in your Admin shell. Confirm `/api/admin/secure/whoami` (from previous pack) returns your claims.
