## 🎯 **COMMON WORKFLOWS**

### **Running Tests Locally:**
```bash
# Unit tests
cd frontend && npm run test:unit

# Integration tests
cd frontend && npm run test:integration

# E2E tests (requires app running)
npm run build && npm run preview
npx playwright test

# All tests
npm run test:all
```

### **Checking Performance:**
```bash
# Bundle size analysis
cd frontend && npm run build:analyze

# Size limits check
cd frontend && npm run size

# Lighthouse audit
npm install -g @lhci/cli
npm run build && npm run preview
lhci autorun
```

### **Checking Accessibility:**
```bash
# Run accessibility E2E tests
npx playwright test tests/e2e/frontend/accessibility

# Check axe-core violations
npx playwright test tests/e2e/frontend/accessibility/a11y-components.spec.ts
```
