### 🚀 MCP Tools

#### 1. `calculate_property_tax`
Calculate property taxes using consciousness-aware algorithms with quantum optimization.

**Parameters:**
- `assessed_value` (required): Property assessed value in dollars
- `property_type`: Type of property (residential, commercial, industrial, timber, agricultural)
- `jurisdiction`: Tax jurisdiction (benton_county, richland, kennewick, west_richland, benton_city)
- `exemptions`: Array of applicable exemptions
- `levy_year`: Tax levy year (2020-2030)
- `consciousness_enhancement`: Enable MIT PhD consciousness enhancements

**Example:**
```json
{
  "assessed_value": 350000,
  "property_type": "residential",
  "jurisdiction": "benton_county",
  "exemptions": ["senior_citizen"],
  "levy_year": 2025,
  "consciousness_enhancement": true
}
```

#### 2. `analyze_levy_forecast`
Analyze historical levy trends and generate predictions using spatiotemporal analytics.

**Parameters:**
- `historical_data` (required): Historical levy data for analysis
- `forecast_years`: Number of years to forecast (1-10)
- `jurisdiction`: Jurisdiction for analysis

**Example:**
```json
{
  "historical_data": [
    {"year": 2020, "total_levy": 5000000, "jurisdiction": "benton_county"},
    {"year": 2021, "total_levy": 5100000, "jurisdiction": "benton_county"},
    {"year": 2022, "total_levy": 5200000, "jurisdiction": "benton_county"}
  ],
  "forecast_years": 5,
  "jurisdiction": "benton_county"
}
```

#### 3. `optimize_tax_strategy`
Optimize tax strategy using quantum algorithms and consciousness processing.

**Parameters:**
- `target_revenue` (required): Target revenue amount in dollars
- `property_values` (required): Property value data for optimization
- `jurisdiction`: Jurisdiction for optimization

**Example:**
```json
{
  "target_revenue": 10000000,
  "property_values": [
    {"assessed_value": 250000, "property_type": "residential", "exemptions": []},
    {"assessed_value": 500000, "property_type": "commercial", "exemptions": []}
  ],
  "jurisdiction": "benton_county"
}
```

#### 4. `get_consciousness_metrics`
Get current consciousness awareness metrics and system status.

**Parameters:** None
