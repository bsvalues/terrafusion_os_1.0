## Quick Start

### Compliance Operations

```bash
# Check current compliance status
npm run compliance:status

# Run FISMA compliance validation
npm run compliance:fisma --full-assessment

# Validate Section 508 accessibility
npm run compliance:accessibility --wcag-2.1-aaa

# Check FedRAMP security compliance
npm run compliance:fedramp --high-baseline

# Run SOC2 operational compliance
npm run compliance:soc2 --type-ii
```

### Audit Preparation

```bash
# Generate audit evidence package
npm run audit:prepare --government

# Start inspector portal
npm run audit:inspector-portal

# Generate compliance reports
npm run compliance:reports --all-frameworks

# Validate audit trail integrity
npm run audit:integrity-check
```
