  • County-level PRD / PRB / COD summary

Which superpower should we build first?

Each unlocks a different part of the PhD audit workflow. Pick the one that changes your work the most.

A

Parcel Evidence Viewer

Click any AI finding → see the individual sales behind it. Ratio scatter plot, sale price vs. AV, sale date, parcel IDs. Answer: "Is this really a rate problem, or are 3 distressed sales poisoning the study?"

Root cause → data problem vs. rate problem vs. outlier
B

Adjustment Simulator ("What If")

Type a proposed adjustment → instantly see projected PRD / PRB / COD before applying. Know the outcome before you commit. Answer: "If I push S1 up 8%, does that fix Reval 3 without breaking Reval 1?"

Fly with instruments, not blind
C

Stratified Equity Report

PRD / PRB / COD broken out by value quintile, age band, size band, and reval area simultaneously. Spot regressivity in low-value vs. high-value parcels. Answer: "Am I equitable across all strata, not just the county average?"

IAAO-standard ratio study depth
D

All Three — Design as a Suite

Parcel Evidence + Adjustment Simulator + Stratified Equity form a complete PhD audit loop. Design them together so data flows between them: outlier exclusion in the evidence viewer feeds the simulator, which feeds the equity report.

Coherent audit system, not three disconnected tools
