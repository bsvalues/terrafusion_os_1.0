CostForge Calibration Workbench — Full Design

The first AI-native county cost matrix calibration system. Four layers working together.

THE FOUR LAYERS
🧠
LAYER 1
AI Diagnostic Engine
Runs continuously. Pulls TerraFusion sales. Computes real PRD/PRB/COD. Classifies every issue. Proposes exact rate changes. Tracks evidence age. Done before you open the tool.
🎛️
LAYER 2
Calibration Cockpit
AI finding queue + working matrix heat map + mass adjustment controls + live PRD/COD recalculation. Expert can accept AI proposals or override with their own judgment. Always non-linear.
📚
LAYER 3
Matrix Version Registry
Git-model versioning. DRAFT → REVIEW → APPROVED → LOCKED → ARCHIVED. Evidence age per factor. Version types: CALIBRATED / MANDATED / PATCH. Immutable history forever.
⚖️
LAYER 4
Governance Engine
Calibration Memo auto-drafts throughout. Sign-off chain enforced. WAC 458-07 compliance checked. DOR audit package generated on demand. Legislative audit package in minutes.
LAYER 1 — AI Diagnostic Engine (What AI Knows Before You Touch Anything)
Data AI pulls from TerraFusion
• All arm's-length sales, current 24-month window
• Each sale matched to assessed value at date of sale
• Building type, reval area, size, age, condition per parcel
• Current locked matrix (what was applied at assessment)
• Prior 4 matrix versions (for drift detection)
• Evidence age per reval area factor
What AI computes and outputs
• Real PRD/PRB per building type AND per reval area
• Real COD by type, by area, by value tier (Low/Mid/High)
• Classification: Rate Problem / Data Problem / External / None
• For Rate Problems: exact $/sqft adjustment to hit PRD target
• County AV impact for each proposed adjustment
• Evidence age flag per reval area (stale > 36 months)
• Parcels to flag to Property Workbench (misclassified)
EXAMPLE AI FINDING — Rate Problem
"Agricultural (A1/A2): 23 arm's-length farm sales, 2023–2025. Median ratio: 0.874 (under-assessed 12.6%). PRD: 1.041 (regressive — lower-value farms over-assessed relative to higher-value). PRB slope: -0.068 (significant). Rate Problem confirmed. Recommended adjustment: +$11.20/sqft (+12.5%) to A1, +$10.69/sqft (+12.5%) to A2. County AV impact: +$23.4M across 847 agricultural parcels. Evidence: strong (23 sales, tight distribution, no outliers flagged)."
EXAMPLE AI FINDING — Data Problem → Flag to Property Workbench
"Commercial Retail (C1), Reval 3: 8 sales analyzed. 2 sales flagged as outliers (parcel IDs 12045-003, 12045-119): sale prices 340% above median — likely mixed-use properties mis-coded as pure retail. Excluding outliers: PRD drops from 1.089 to 1.002. No rate adjustment needed. Flagging 2 parcels to Property Workbench for classification review."

LAYER 3 — Matrix Version Registry (Backend Schema)
MatrixVersion record stores:
id, countyId, version (semver)
status: DRAFT|REVIEW|APPROVED|LOCKED|ARCHIVED
versionType: CALIBRATED|MANDATED|PATCH
effectiveDate, lockedAt, lockedBy
rateSnapshot: JSON (full matrix at lock)
triggeringEvent: string
salesWindowStart, salesWindowEnd
salesExclusionRules: JSON
prdBefore, prdAfter, prbBefore, prbAfter
codBefore, codAfter
countyAvImpact: decimal
signOffChain: JSON (analyst→chief→assessor)
calibrationMemoId: FK
nextReviewDate
parentVersionId: FK (for patch lineage)
RevalAreaEvidenceAge tracks:
matrixVersionId, revalArea
factor (area multiplier)
lastRatioStudyDate
saleCount, medianRatio
evidenceAgeMonths (computed)
evidenceStatus: CURRENT|AGING|STALE|CRITICAL
— CURRENT: <24 months
— AGING: 24–36 months
— STALE: 36–60 months (flag)
— CRITICAL: >60 months (WAC 458-07 risk)
State/DOR Role (cross-county read)
Sees: aggregate PRD/PRB/COD per county, no parcel data, no individual rates. Used for equalization analysis. Per-authorization only.
LAYER 4 — Governance Engine (What Gets Auto-Generated)
Calibration Memo
Auto-drafts as appraiser works. All 8 required sections per SOP §5.3. Fills in PRD/PRB before/after, sales universe, change made, AV impact. Appraiser adds context, signs. Done.
DOR Equalization Package
On-demand: all matrix versions + memos + ratio studies for any date range. DOR format. Includes PRD/COD trend charts. Takes 4 minutes, not 3 weeks.
Legislative Audit Package
5-year equity trend report. Every rate change with market evidence. WAC 458-07 compliance checklist. Value-tier equity analysis. BOR testimony scripts from AI. Signed provenance chain.
Matrix Provenance Report
For new staff: "Why is Warehouse $52.65?" AI traces every rate to its calibration event, the sales evidence, who signed it, how old it is. Full inheritance brief on day one.
Drift Alert
"Warehouse hasn't changed in 3 cycles but market appreciated 18%. Under-assessed by est. 8–12%." Pushed to appraiser proactively — no one has to remember to check.
Property Workbench Flagging
Data problems identified by AI (misclassified parcels) are routed directly to Property Workbench as flagged audit items. CostForge never touches parcel-level records.
