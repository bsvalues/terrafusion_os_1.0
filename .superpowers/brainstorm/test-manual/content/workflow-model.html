Calibration Workbench — Core Workflow Model

The PhD Chief Appraiser needs to Audit → Diagnose → Adjust → Verify → Document. Which paradigm fits best?

A

Guided Calibration Loop

Step-by-step wizard: Triage → Drill → Diagnose → Adjust → Verify → Document. Each phase unlocks the next. Structured, auditable, defensible for BOR hearings. Every action is traceable.

① TRIAGE  →  ② DRILL  →  ③ DIAGNOSE  →  ④ ADJUST  →  ⑤ VERIFY  →  ⑥ MEMO
Currently: PRD=1.000 ✓  |  COD=26.1% ⚠  |  0 outlier cells
AI diagnosis: Cross-type spread drives COD. Not a rate problem — it's a type-mix problem. Recommended: run segmented ratio study per type.

Pros

  • Defensible audit trail
  • Enforces Benton Method SOP
  • Less cognitive load
  • Auto-generates Calibration Memo

Cons

  • Linear flow — expert users may want to jump
  • More clicks to get to adjustment
B

Command-Center Power Tool

All panels live simultaneously: heat map, drill-down parcel table, rate sliders, live PRD/COD recalculation. The expert sees everything at once, adjusts on the fly, and runs the calibration loop at their own pace.

C

AI-First Conversational Workbench

Natural language + AI reads the data and drives the investigation. "Why is COD 26.1%?" → AI explains. "What needs to change?" → AI proposes rate adjustments. "Apply it" → AI updates the matrix. Visual panels appear contextually as the AI surfaces findings.

Chief:
"COD is 26.1% — is this a rate problem or a data problem?"
AI:
COD of 26.1% is driven by cross-type spread ($44/sqft Warehouse vs $216/sqft Hospital), not within-type variance. Each type has COD 8.2% — well within IAAO limits. This is a type-mix diagnostic signal, not a calibration error. No rate adjustment needed. Recommend: run stratified ratio study per type to confirm base rates are market-supported.
Chief:
"Show me Hospital sales. Are any outliers?"

Pros

  • Highest AI leverage
  • Zero-friction for expert users
  • AI distinguishes data vs rate problems automatically

Cons

  • Requires TerraFusion AI module
  • Less structured audit trail (needs wrapping)
  • Unfamiliar paradigm for some staff
