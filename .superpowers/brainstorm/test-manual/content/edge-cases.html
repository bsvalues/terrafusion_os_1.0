Edge Cases — Multi-County, State DOR, Legislative Audit

TerraFusion serves 39+ WA counties. The matrix versioning system must satisfy all of these simultaneously.

Edge Case 1 — State DOR Equalization Audit
📋 Scenario: State DOR calls. They want every ratio study and calibration record for Benton County, 2020–2025.
Without TerraFusion versioning
Staff searches shared drives, email threads, Excel files. 2021 calibration memo is missing. 2022 ratio study is in a format the DOR doesn't recognize. Chief appraiser spends 3 weeks assembling a package that still has gaps. Potential equalization order.
With TerraFusion
AI generates DOR audit package in minutes: all matrix versions with timestamps, every Calibration Memo with sign-off chain, ratio study evidence linked to each version change, PRD/PRB/COD trends across all years. Exported in DOR-required format.
Output: "Benton County Equalization Audit Package 2020–2025 — generated in 4 minutes"
What TerraFusion must store per matrix version to satisfy DOR:
✓ Matrix snapshot (all rates at lock date)
✓ Triggering event (PRD/PRB/COD that prompted review)
✓ Sales data universe (window, cleaning rules, exclusions)
✓ Diagnostics summary (before/after PRD/PRB)
✓ Change description (old rate → new rate, version numbers)
✓ Sign-off chain (analyst → chief appraiser → assessor)
✓ Effective date
✓ Verification results (post-change ratio study)
✓ Next review date
Edge Case 2 — State-Mandated Equalization Order
⚡ Scenario: State DOR issues an equalization order — Benton County must raise all residential assessments by 8% before tax roll closes.
This is NOT a locally-driven calibration. It's state-mandated. The matrix version for this change needs a special classification: MANDATED vs CALIBRATED. The Calibration Memo still generates but the triggering event is "State DOR Equalization Order #2025-47" not a local ratio study finding.
Version Classification
v2025.2-MANDATED
Trigger: DOR Order #2025-47
Scope: R1 residential only
Change: SFR base rate +8%
Authority: State DOR (overrides local)
AI Behavior
AI pre-fills memo with DOR order citation. Calculates exact rate change needed. Shows county AV impact (+$186M). Flags which reval areas are affected. Generates taxpayer communication template. Cannot be overridden by local calibration tools.

Sovereign County Model (current)
Each county's matrix is fully isolated. A Benton appraiser cannot see Yakima's rates. Multi-county access requires explicit authorization. This is FISMA-compliant and legally correct.
✓ Already implemented in TerraFusion OS
State DOR Needs Cross-County View
The DOR needs to see all counties' ratios to issue equalization. TerraFusion needs a State DOR role that has read-only access to aggregate metrics (not individual parcel data) across all counties. Benchmarking without exposing sovereign data.
⚠ Design needed: aggregated cross-county report
Cross-County Benchmarking (Chief Appraiser View)
With proper authorization, a chief appraiser can see anonymized or authorized peer county rates. "How does Benton's Agricultural rate compare to the Eastern WA median?" AI answers: "Benton Agricultural ($89.73/sqft) is 6.2% above the Eastern WA county median ($84.50). Within normal variance — no action indicated." This requires inter-county data sharing agreement, not automatic.
