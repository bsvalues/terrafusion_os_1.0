## Typography Hierarchy

**Contrast Ratios:**

- **Primary Text on Dark:** White (`#ffffff`) on Dark Blue (`#001529`) = 19.36:1
- **Accent Text on Dark:** Cyan (`#00e5ff`) on Dark Blue (`#001529`) = 14.2:1
- **Secondary Text:** 70% opacity for good readability
- **Muted Text:** 50% opacity for de-emphasized content


**Size Scale (Tailwind):**

```css
text-xs: 12px    /* Captions, metadata */
text-sm: 14px    /* Secondary content */
text-base: 16px  /* Primary body text */
text-lg: 18px    /* Component labels */
text-xl: 20px    /* Card titles */
text-2xl: 24px   /* Subsection headers */
text-3xl: 36px   /* Section headers */
text-4xl: 48px   /* Main titles */
```

**Line Heights:**

- **Headings:** `leading-tight` (1.25)
- **Body Text:** `leading-normal` (1.5)
- **Captions:** `leading-relaxed` (1.625)


**Spacing Patterns:**

```css
--spacing-sm: 8px   /* gap-2, p-2 */
--spacing-md: 16px  /* gap-4, p-4 */
--spacing-lg: 32px  /* gap-8, p-8 */
```

**Visual Effects:**

- **Glassmorphic:** `backdrop-blur-xl` with `bg-[#001529]/70`
- **Borders:** `border-[#00e5ff]/20` for subtle definition
- **Shadows:** `0 0 20px rgba(0,229,255,0.1)` for depth
- **Hover States:** Scale transforms and glow intensity changes


This design system ensures consistent visual hierarchy, accessibility, and the distinctive Terrafusion aesthetic across all components.
