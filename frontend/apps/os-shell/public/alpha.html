  • Clicking a result opens the Workbench with live data
  • All 9 tabs show honest state (real / no-data, never fake)
  • Forge year selector reflects actual PACS layers
  • No "Demo data" badges on parcels loaded from PACS

  • Search works for any parcel by ID, address, or owner
  • Parcel detail loads within 3 seconds
  • Values match what you see in Harris PACS for the same parcel
  • No crashes, no infinite spinners, no blank tabs without explanation

Your role

  • Use the app as you would in a real work session
  • Look up parcels you know well — spot any wrong data immediately
  • Open exploration: 30 min free-form + 30 min scenarios

🚀 Setup

Before you start

  1. Open http://localhost:5173 in Chrome or Edge
  2. You should see the TerraFusion OS desktop (dark background, cyan accents)
  3. Press Ctrl+K to open the command palette search bar
  4. Type any parcel ID, address, or owner name and press Enter
  5. Click a result — the Workbench should open in a floating window
  6. Verify the "Live" badge appears (not "Demo data")
ℹ️ Backend must be running at localhost:5000. If you see "Backend offline" in the status bar, contact the dev team before testing.
⚠️ Pilot Runtime also required. Dais, Clerk, Treasury, Audit, Dossier, and Pilot tabs route all tool invocations through a separate process at localhost:4317. If that process is not running, those 6 tabs will render but every tool card invocation will fail with a network error. Contact the dev team if tool cards show errors on first click.

🧪 Test Scenarios

Scenario 1 — Parcel ID search

Pick any parcel ID you know from Benton County. Type it in Ctrl+K.

  1. Press Ctrl+K — command palette opens (no launcher dialog)
  2. Type the parcel ID (e.g. 101843030001006)
  3. Select the result from the dropdown
  4. Workbench opens — Summary tab is active
  5. Check: owner name, address, and AV match PACS
  6. Check: "Live" badge visible, no "Demo data" badge
Pass when: Values match PACS. No demo badge. No crash.

Scenario 2 — Address search

Search by a street address you know in Benton County.

  1. Press Ctrl+K
  2. Type a partial street name (e.g. Clearwater)
  3. Multiple results should appear — select one
  4. Workbench opens with correct property
  5. Navigate to Forge tab — verify year selector appears
Pass when: Address search returns relevant results. Forge year selector shows ≥1 layer.

Scenario 3 — Forge year layers

Verify the Forge tab shows real PACS year history, not a static dropdown.

  1. Open any parcel in the Workbench
  2. Click the Forge tab
  3. The "Tax Year" selector should show year options pulled from PACS
  4. If years have lock state, look for 🔒 or 🔓 badge next to the year
  5. Change the year — context panel below the selector should update
  6. Check AV/MV values in the context panel match PACS for that year
Pass when: Year list comes from PACS (shows "PACS · N layers" badge). Values update per year.

Scenario 4 — Multi-parcel session

Open 3 different parcels in the same session.

  1. Open parcel A → Workbench window appears
  2. Press Ctrl+K again → search for parcel B → open it
  3. A second Workbench window opens (or focuses existing if same parcel)
  4. Open parcel C the same way
  5. Verify each window shows the correct parcel's data independently
  6. Switch between windows — no data bleed between parcels
Pass when: 3 parcels open, each shows its own data, no cross-contamination.

Scenario 5 — MWUX tab surface check

Verify every tab loads a working surface before you invoke any tools — no blank screens, no stuck spinners.

  1. Open any parcel in the Workbench
  2. Click through all 9 tabs: Summary, Forge, Atlas, Dais, Clerk, Treasury, Audit, Dossier, Pilot
  3. Each tab should finish loading within 3 seconds
  4. MWUX tabs (Dais, Clerk, Treasury, Audit, Dossier, Pilot) should show tool cards or panels — not a blank screen
  5. If a tab shows an error banner, note the correlationId and report it as a defect
Pass when: All 9 tabs load. MWUX tabs show their tool surfaces. No stuck spinners.
