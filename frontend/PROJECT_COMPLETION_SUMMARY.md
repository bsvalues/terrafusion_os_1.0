## 🚀 Deployment Guide

### Prerequisites
- Node.js 20.x
- .NET 8.0 SDK
- Docker 24.x
- Kubernetes 1.28+
- PostgreSQL 15.x
- Redis 7.x (optional, for caching)

### Local Development Setup
```bash
# Clone repository
git clone https://github.com/bsvalues/terrafusion_os_1.0.git
cd terrafusion_os_1.0

# Backend setup
cd backend
dotnet restore
dotnet build
dotnet ef database update --project TerraFusion.Data

# Frontend setup
cd ../frontend
npm install
npm run dev

# Start backend services
cd ../backend
dotnet run --project TerraFusion.API --urls "http://localhost:5000"
dotnet run --project TerraFusion.Consciousness --urls "http://localhost:3004"
```

### Docker Deployment
```bash
# Build all containers
docker-compose build

# Start all services
docker-compose up -d

# View logs
docker-compose logs -f

# Stop all services
docker-compose down
```

### Kubernetes Production Deployment
```bash
# Apply Kubernetes manifests
kubectl apply -f kubernetes/namespace.yaml
kubectl apply -f kubernetes/configmap.yaml
kubectl apply -f kubernetes/secrets.yaml
kubectl apply -f kubernetes/postgres-deployment.yaml
kubectl apply -f kubernetes/backend-deployment.yaml
kubectl apply -f kubernetes/frontend-deployment.yaml
kubectl apply -f kubernetes/ingress.yaml

# Verify deployments
kubectl get pods -n terrafusion
kubectl get services -n terrafusion

# Check application logs
kubectl logs -f deployment/terrafusion-api -n terrafusion
kubectl logs -f deployment/terrafusion-consciousness -n terrafusion

# Scale deployments
kubectl scale deployment terrafusion-api --replicas=5 -n terrafusion
kubectl scale deployment terrafusion-consciousness --replicas=3 -n terrafusion
```
