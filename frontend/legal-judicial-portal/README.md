# TerraFusion Legal & Judicial Portal

## Overview

The **TerraFusion Legal & Judicial Portal** is a comprehensive court case management and judicial administration system designed specifically for Benton County Superior Court System in Washington State. This portal provides complete digital transformation of legal proceedings, case tracking, hearing management, and judicial personnel coordination.

## ⚖️ Core Features

### 1. Legal Dashboard
- **Real-time court system overview** with live metrics
- **Case completion rates** and efficiency tracking
- **Court utilization statistics** across all courtrooms
- **Performance analytics** with visual charts and graphs
- **Judge availability monitoring** and workload distribution

### 2. Case Management System
- **Comprehensive case tracking** from filing to resolution
- **Multi-category support**: Civil, Criminal, Family, Probate, Traffic, Small Claims, Juvenile, Administrative
- **Case status monitoring**: Filed, Pending, In Progress, Scheduled, Closed, Appealed, Dismissed
- **Party management**: Plaintiff/Defendant tracking with attorney assignments
- **Advanced search and filtering** by case number, parties, type, status
- **Detailed case views** with complete case history and documentation

### 3. Court Calendar & Scheduling
- **Comprehensive hearing calendar** with daily, weekly, monthly views
- **Hearing type management**: Arraignment, Trial, Sentencing, Motion, Conference, Appeal
- **Courtroom scheduling** across 8 available courtrooms
- **Judge assignment coordination** based on availability and specialization
- **Participant tracking** for all hearing attendees
- **Document requirements** management for each hearing
- **Time slot optimization** with duration management

### 4. Judicial Personnel Management
- **Judge profile management** with complete judicial records
- **Specialization tracking**: Traffic violations, small claims, family law, criminal cases, DUI, domestic violence
- **Caseload monitoring** with maximum capacity tracking
- **Availability scheduling** with weekly time slot management
- **Workload distribution** analytics and balancing
- **Experience tracking** and years of service

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ with npm
- TerraFusion Legal & Judicial Service running on port \${{TF_PORT_5290:-5290}}
- Modern web browser with JavaScript enabled

### Installation
```bash
# Navigate to project directory
cd /workspaces/terrafusion_os_1.0/frontend/legal-judicial-portal

# Install dependencies
npm install

# Start development server
npm run dev

# Access portal at http://localhost:\${{TF_FRONTEND_3019_PORT:-3019}}
```
