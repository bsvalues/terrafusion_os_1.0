### 🔒 **Intelligent Privacy Protection**
1. **Every query is analyzed** for sensitive information (PII, SSNs, names)
2. **Sensitive data stays local** - processed by your private Ollama LLM
3. **Safe calculations go to cloud** - leveraging powerful APIs for speed
4. **Mixed data is anonymized** - identifiers removed before cloud processing

## 🔧 INSTALLATION & REQUIREMENTS

### ✅ **System Requirements**
- **Python 3.8+** (Recommended: 3.11)
- **8GB RAM minimum** (16GB recommended for optimal performance)
- **20GB disk space** (for models and historical data)
- **Internet connection** (for model downloads and cloud APIs)

### 📦 **Dependencies**
Automatically installed by the launch script:
- **Ollama** - Local LLM hosting
- **Python packages** - aiohttp, pandas, numpy, pytorch, etc.
- **LLM models** - llama2:7b for local processing

### ⚙️ **Configuration**
After first launch, update `.env` with your API keys:
```bash
OPENAI_API_KEY=sk-your-openai-key-here
ANTHROPIC_API_KEY=your-anthropic-key-here
BENTON_ASSESSOR_KEY=your-benton-county-key-here
```
