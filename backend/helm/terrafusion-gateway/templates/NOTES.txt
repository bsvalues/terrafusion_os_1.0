🌐 GATEWAY STATUS

1. Get the application URL:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  https://{{ $host.host }}
{{- end }}
{{- else }}
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "terrafusion-gateway.fullname" . }} 3002:{{ .Values.service.port }}
  echo "Visit http://127.0.0.1:3002 to access gateway"
{{- end }}

2. Check pod status:
   kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "terrafusion-gateway.name" . }}"

3. View gateway logs:
   kubectl logs --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "terrafusion-gateway.name" . }}" --follow

4. Test routing:
   curl -k https://{{ (index .Values.ingress.hosts 0).host }}/api/health
   curl -k https://{{ (index .Values.ingress.hosts 0).host }}/consciousness/health
   curl -k https://{{ (index .Values.ingress.hosts 0).host }}/operations/health
