📊 ACCESS SERVICE

1. Get the application URL:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  https://{{ $host.host }}
{{- end }}
{{- else }}
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "terrafusion-operations.fullname" . }} 5003:{{ .Values.service.port }}
{{- end }}

2. Check pod status:
   kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "terrafusion-operations.name" . }}"

3. View county sync logs:
   kubectl logs --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "terrafusion-operations.name" . }}" --follow

4. Monitor sync metrics:
   kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "terrafusion-operations.fullname" . }} 5003:5003
   curl http://localhost:5003/metrics | grep operations_county_sync
