    * feat(deploy): Deploy Apply + Receipt Constitution v1.0.0
    
    Phase 3 of Deploy Constitution: RuntimeCert-driven deployment with
    immutable audit receipts.
    
    New Commands:
    - tf deploy apply --env <env> --bundle <dir> [--dry-run] [--ci]
    - tf deploy receipt --bundle <dir> [--ci]
    
    Core Invariants:
    A) Verify-first: apply MUST run release verify before any action
    B) Mode detection: uses existing detect_mode() (k8s/compose)
    C) Dry-run safety: validates without mutations, receipt status=dry_run
    D) Receipt creation: atomic write to <bundle>/proofs/deploy_receipt.json
    
    Receipt Schema v1.0.0:
    - version, timestamp, environment, mode
    - bundle.path, bundle.hash, bundle.verified
    - git.sha, git.tag
    - action (apply|dry_run), status (success|failed|dry_run)
    - steps[] (verify, preflight, execute, health)
    - error (code, message) or null
    
    Exit Codes:
    - 0: success or dry_run
    - 1: failure (verify failed, gate failed, execution failed)
    - 2: invalid invocation (missing flags, bad paths, unsupported mode)
    
    v1.0.0 Governance-Only:
