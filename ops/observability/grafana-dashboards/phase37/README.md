## Overview

This dashboard pack provides county-ready Grafana dashboards for monitoring Atlas forecast engine, SystemGPT swarm policies, anomaly detection, and telemetry ingestion.

## Installation

### Prerequisites

1. Prometheus instance scraping TerraFusion `/metrics` endpoint
2. Grafana 9.0+ with Prometheus datasource configured
3. Datasource UID: `prometheus` (or update in JSON files)

### Import Steps

1. Open Grafana → Dashboards → Import
2. Upload JSON file or paste contents
3. Select Prometheus datasource
4. Click Import

### Bulk Import (Grafana Provisioning)

```yaml
# /etc/grafana/provisioning/dashboards/terrafusion.yaml
apiVersion: 1
providers:
  - name: 'TerraFusion Phase 37'
    orgId: 1
    folder: 'TerraFusion'
    type: file
    disableDeletion: false
    updateIntervalSeconds: 30
    options:
      path: /var/lib/grafana/dashboards/phase37
```

Copy dashboard JSON files to `/var/lib/grafana/dashboards/phase37/`.

## Customization

### Datasource

Replace `"uid": "prometheus"` with your Prometheus datasource UID in all JSON files.

### Thresholds

Adjust threshold values based on your county's baseline:

```json
"thresholds": {
  "mode": "absolute",
  "steps": [
    { "value": 0, "color": "green" },
    { "value": YOUR_WARNING_THRESHOLD, "color": "yellow" },
    { "value": YOUR_CRITICAL_THRESHOLD, "color": "red" }
  ]
}
```

## Troubleshooting

### No Data

1. Verify Prometheus is scraping `/metrics` endpoint
2. Check metric names exist: `curl http://your-service/metrics | grep atlas_`
3. Verify datasource connection in Grafana

### Missing Counties

Counties only appear after emitting at least one metric. Initialize with:

```csharp
metricsCollector.IncrementForecastGenerated("your-county-id");
```

### Dashboard Import Errors

1. Validate JSON: `jq . dashboard.json`
2. Check Grafana version compatibility (requires 9.0+)
3. Verify `schemaVersion: 39` is supported
