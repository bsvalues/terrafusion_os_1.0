# data - Data Management and Intelligence Hub

**Status**: Operational ✅  
**Purpose**: Multi-county data management and intelligence coordination  
**Classification**: Data Management and County Intelligence Systems  

## Quick Start

### Data Management Operations
```bash
# Initialize county data systems
npm run data:init --multi-county

# Synchronize county data
npm run data:sync --counties=yakima,cowlitz,benton

# Run intelligence analytics
npm run intelligence:analyze --county-specific

# Validate data quality
npm run data:validate --comprehensive
```

### County Data Operations
```bash
# Yakima County flagship data
npm run data:yakima --flagship-optimization

# Cowlitz County customized data
npm run data:cowlitz --workflow-optimization

# Benton County production data
npm run data:benton --harris-pacs-sync

# Multi-county coordination
npm run data:coordinate --multi-county
```
