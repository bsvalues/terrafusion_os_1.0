For ArcMap users migrating to ArcGIS Pro

Throughout the documentation, the names ArcGIS Desktop and ArcMap are often used interchangeably to refer to ArcMap, ArcCatalog, ArcGlobe, and ArcScene.

Nearly all the functionality you're accustomed to using in ArcMap is available in ArcGIS Pro, along with new functionality. This section provides an overview of ArcGIS Pro in relation to other ArcGIS Desktop applications in the following areas:

  • Application startup
  • User interface
  • Documents compared to projects
  • Migrating existing work
  • Common workflows

Learn how to import an ArcMap document to bring your existing work into ArcGIS Pro.

Find additional resources on the Migrate from ArcMap tab, or view answers to frequently asked questions about ArcMap.
