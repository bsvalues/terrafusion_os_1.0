Install a localized version of ArcGIS Pro

For general installation steps, see Install ArcGIS Pro. Additional information is provided here for localized versions of ArcGIS Pro or language packs that you have downloaded.

Note:

By default, ArcGIS Pro runs in the language that matches your Windows display language if you have the appropriate language pack installed. For example, if your Windows display language is French, and you install a French language pack, ArcGIS Pro runs in French. To run ArcGIS Pro in a language that does not match your Windows display language, you must change your language options.

Install a localized version of ArcGIS Pro

A localized setup (Setup.exe) includes setup files for both the core ArcGIS Pro product and a specific language pack:

  • ArcGISPro.msi
  • Pro<language>LP.msi

Both setups are installed by Setup.exe. For example, if you run Setup.exe for ArcGIS Pro Spanish, both ArcGIS Pro and the Spanish language pack are installed.

Two different Add/Remove Program items are created for ArcGIS Pro and the language pack. Uninstalling one does not uninstall the other.

Install language packs

Any language packs that are downloaded separately from ArcGIS Pro are also installed separately. To install a language pack that is not part of a localized version, you run only the Pro<language>LP.msi file for the language.

Note:

Language packs are downloaded and installed separately from ArcGIS Pro. You can download them from My Esri if you have permission in your organization to download software.
