## 🚀 Ready for Development

### To Run the Application

```bash
cd pacs-quantum-ui
npm install
npm run dev
```

The application will start on `http://localhost:5174` (or next available port if 5174 is taken)

### Build for Production

```bash
npm run build
```

Output will be in the `dist/` directory, ready for deployment.
