## 📋 **GETTING STARTED**

### **Prerequisites**
```bash
# System Requirements
- Python 3.11+
- Docker 20.10+
- 16GB RAM minimum
- 500GB storage
- Ubuntu 20.04+ or Windows 10+
```

### **Quick Start**
```bash
# Clone the repository
git clone https://github.com/bsvalues/terrafusion_os_1.0.git
cd terrafusion_os_1.0

# Install dependencies
pip install -r requirements.txt

# Start Trust Fabric
cd trust-fabric && python core.py &

# Start all government services
for service in services/terrafusion-*.py; do
    nohup python "$service" > "logs/$(basename $service .py).log" 2>&1 &
done

# Verify deployment
curl http://localhost:\${{TF_API_PORT:-5000}}/api/trust-fabric/services
```
