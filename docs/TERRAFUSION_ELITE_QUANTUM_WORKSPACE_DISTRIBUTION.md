## 🚀 Installation & Setup

### Quick Start (Recommended)

```bash
# 1. Download distribution package
curl -L https://github.com/bsvalues/terrafusion-elite-quantum-v12/archive/main.tar.gz | tar -xz

# 2. Initialize workspace orchestrator
cd terrafusion-elite-quantum-v12
npm install -g ./workspace-orchestrator.js

# 3. Set up your tier (choose one)
./deployment/deploy-tier1.sh    # Core platform team
./deployment/deploy-tier2.sh    # Domain specialist team  
./deployment/deploy-tier3.sh    # Extended ecosystem team

# 4. Validate Factor 12 readiness
./deployment/validate-quantum.sh --target=12

# 5. Open master workspace
code tier1-core/master.code-workspace
```

```bash

  --target=12
```
