# TerraForge Current Use Command Center — Phase 1

Module ID: `terra-current-use`

## Includes

- Current Use Workbench tab
- classification/lifecycle types
- evidence checklist
- assessor timeline
- rollback rule engine
- rollback calculator UI
- calculation explanation ledger
- mock API adapter
- draft notice placeholder
- rollback tests

## Install

Copy `src/modules/terra-current-use` into the TerraFusion frontend source tree.

Then wire the tab using `PROPERTY_WORKBENCH_INTEGRATION.md`.

## Phase 1 warning

Interest calculation is simplified and must not be used for final tax notice issuance without production statutory interest implementation.
