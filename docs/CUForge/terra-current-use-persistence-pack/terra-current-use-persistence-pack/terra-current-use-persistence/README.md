# Terra Current Use Persistence Pack

Adds persistence-ready entity/configuration/repository shapes for the TerraForge Current Use Command Center.

## Includes

- EF entity classes
- EF configuration classes
- DbContext extension
- repository interface and implementation
- manual SQL baseline
- seed data
- persistence wiring guide

## Warning

`CurrentUseRepository.cs` uses `DbContext` directly as a placeholder. Replace with the actual TerraFusion application DbContext type before compile.
