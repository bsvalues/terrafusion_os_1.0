# Terra Current Use AI Assist Pack

Adds safe TerraPilot/AI-assist scaffolding for Current Use review.

## Includes

- frontend AI types/client/panel
- backend AI DTOs/service/controller
- guardrails
- prompt templates
- tests
- wiring guide

## Boundary

AI is explain-only review support. It cannot approve, deny, waive, finalize, override, or issue.
