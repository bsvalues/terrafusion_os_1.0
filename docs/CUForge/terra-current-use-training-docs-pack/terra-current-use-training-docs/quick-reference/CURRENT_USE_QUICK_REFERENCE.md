# Current Use Quick Reference

## Common Actions

### Run Rollback

1. Open Current Use tab.
2. Review classification.
3. Click Run Rollback Calculation.
4. Review explanation ledger.
5. Confirm policy version.
6. Do not issue final notice until supervisor approval.

### Request Missing Evidence

1. Open Evidence Checklist.
2. Review missing items.
3. Generate Missing Evidence Request preview.
4. Route for approval if issuing.
5. Link final notice to Dossier.

### Review Continuance

1. Confirm transfer event.
2. Confirm owner intent response.
3. Confirm classification continuation evidence.
4. Create Dais task if waiting on owner.
5. Trace the review action.

## Red Flags

- missing levy rate
- missing income proof
- owner/operator mismatch without lease
- unresolved policy version
- issued notice without Dossier document ID
- calculation with placeholder interest
