# Current Use Role Quick Reference

## Viewer

Can view records and audit trace.

## Appraiser

Can review, calculate, preview notices, manage evidence, and schedule inspections.

Cannot issue final notices.

## Supervisor

Can approve and issue notices, lock rollback calculations, and manage appeals.

## Treasurer

Can view payment handoff and mark payment paid.

## Auditor

Can view records, evidence, policies, analytics, and trace.

## Admin

Can manage all module configuration.
