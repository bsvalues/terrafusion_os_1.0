# Current Use Training Deployment Plan

## Phase 1 — Internal Team

Audience:

- project team
- lead appraiser
- assessor analyst

Goal:

- validate terminology
- validate rollback presentation
- validate notice controls

## Phase 2 — Current Use Desk

Audience:

- staff who manage forms, evidence, and owner contact

Goal:

- validate evidence checklist and notice flow

## Phase 3 — Supervisors

Audience:

- chief deputy
- assessor supervisor

Goal:

- validate approval gates and audit defensibility

## Phase 4 — Treasurer Liaison

Audience:

- payment/collection staff

Goal:

- validate payment handoff model
