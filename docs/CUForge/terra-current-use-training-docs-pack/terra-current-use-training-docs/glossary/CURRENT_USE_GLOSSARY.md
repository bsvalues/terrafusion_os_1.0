# Current Use Glossary

## Additional Tax

The difference between tax paid under Current Use value and tax that would have been paid under true and fair value.

## Classified Acres

Acres enrolled in Current Use classification.

## Continuance

Review after transfer to determine whether classification may continue.

## Dossier

TerraFusion document/evidence system.

## Forge

TerraFusion valuation and calculation domain.

## Homesite Exclusion

Area excluded from classified land treatment for homesite purposes.

## Policy Version

The active rule pack used when calculation is performed.

## Rollback

Additional tax, interest, and penalty calculation following removal or withdrawal.

## TerraTrace

Append-only audit spine.

## True and Fair Value

Market value used to compare against Current Use assessed value.
