# Current Use FAQ

## Does the system decide whether land qualifies?

No. It supports staff review. Authorized county staff make final determinations.

## Can AI approve or deny classification?

No. AI is explain-only and advisory.

## Can notices be issued automatically?

No. Final issuance requires authorized approval.

## Where are documents stored?

Documents are stored in Dossier. Forge stores document references and review metadata.

## Where does audit history live?

TerraTrace owns immutable audit history.

## What happens if a calculation is wrong?

Do not delete it. Mark it for review, create a corrected calculation version, and append a Trace correction event.

## Can rollback calculations change when rules change?

No historical calculation should silently change. Calculations reference the rule and policy version used.
