# Current Use Staff Onboarding Checklist

## Access

- [ ] User has correct Current Use role.
- [ ] User can open Property Workbench.
- [ ] User can see Current Use tab.
- [ ] User can view evidence.
- [ ] User can view Trace.

## Training

- [ ] Completed lifecycle overview.
- [ ] Completed rollback exercise.
- [ ] Completed evidence exercise.
- [ ] Completed notice preview exercise.
- [ ] Completed security/role review.

## Validation

- [ ] User can explain calculation ledger.
- [ ] User understands notices require approval.
- [ ] User understands AI is advisory only.
- [ ] User understands corrections are append-only.
