# Current Use Command Center — Supervisor Manual

## Supervisor Responsibilities

Supervisors review high-impact actions:

- rollback calculation lock
- notice approval
- final notice issuance
- removal workflow readiness
- appeal packet readiness
- policy version confirmation

## Approval Checklist

Before approving a notice:

- [ ] Parcel ID verified
- [ ] Owner name verified
- [ ] Classification type verified
- [ ] Removal/withdrawal reason verified
- [ ] Rollback calculation reviewed
- [ ] Policy version reviewed
- [ ] Evidence packet reviewed
- [ ] Response deadline verified
- [ ] Human-review disclaimer removed only after final approval workflow
- [ ] Dossier document linked
- [ ] TerraTrace event emitted

## Never Approve If

- rollback values are incomplete
- policy version is unresolved
- interest calculation is marked placeholder
- evidence packet is missing required documents
- appeal/reclassification deadline is unclear
