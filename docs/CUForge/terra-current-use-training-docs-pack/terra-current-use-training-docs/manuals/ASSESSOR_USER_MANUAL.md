# Current Use Command Center — Assessor User Manual

## Purpose

The Current Use Command Center helps assessor staff manage classified land lifecycle, evidence, rollback exposure, notices, audit history, and operational handoffs.

It does not replace staff judgment.

## Main Screens

### Parcel Overview

Shows:

- classification type
- lifecycle state
- owner/operator
- classified acres
- homesite exclusion
- evidence completeness
- rollback exposure
- risk status

### Rollback Calculator

Used to estimate additional tax, interest, penalty, and total due.

Staff should review:

- rollback years
- source values
- levy rates
- interest calculation
- penalty status
- statutory exception flags
- explanation ledger
- policy version

### Evidence Checklist

Shows missing, received, reviewed, accepted, stale, or rejected evidence.

### Notices

Notice preview is draft-only until approved.

Controlled issuance requires authorized approval.

### TerraTrace

Shows append-only audit events.

Corrections are added as new events.

## Staff Rule

Do not treat AI, analytics, or risk flags as final determinations.
