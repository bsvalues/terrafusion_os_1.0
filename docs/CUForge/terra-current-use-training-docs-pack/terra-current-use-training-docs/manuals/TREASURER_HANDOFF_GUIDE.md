# Current Use Treasurer Handoff Guide

## Purpose

The Treasurer handoff packet communicates rollback liabilities from assessor calculation to collection.

## Treasurer Owns

- collection
- receipts
- payment status
- accounting reference numbers

## Assessor/Forge Owns

- rollback calculation
- calculation version
- additional tax
- interest
- penalty
- explanation ledger

## Handoff Steps

1. Assessor locks rollback calculation.
2. Payment packet is generated.
3. Packet is sent to Treasurer.
4. Treasurer assigns reference number.
5. Payment status is updated.
6. Receipt number is linked.
7. TerraTrace records the payment event.
