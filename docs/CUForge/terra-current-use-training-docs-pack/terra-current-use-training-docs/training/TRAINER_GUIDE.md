# Current Use Trainer Guide

## Training Session Structure

### Part 1 — Concept

Explain Current Use as a lifecycle:

```txt
Application → Active → Monitoring → Continuance → Removal/Withdrawal → Appeal/Reclass → Closed
```

### Part 2 — Parcel Review

Use demo parcel CU-DEMO-001.

Show:

- classification
- acres
- evidence
- rollback
- trace

### Part 3 — Rollback

Explain:

- rollback years
- true and fair value
- current-use value
- levy rate
- interest
- penalty
- policy version

### Part 4 — Notice Control

Explain:

- preview
- approval
- issuance
- Dossier document
- Trace event

### Part 5 — Practice

Have staff complete:

- run rollback
- identify missing evidence
- explain calculation
- find audit event
