
# Current Use Call-Center Script

## Opening

I can help explain what the Current Use notice or estimate is referring to.

## Key Explanation

Current Use classification can reduce assessed value while land remains in qualifying use. If land is removed or withdrawn, additional tax, interest, and possibly penalty may apply.

## Do Not Say

- You definitely owe this amount.
- You qualify or do not qualify.
- The penalty is waived.
- The appeal will be approved.

## Safe Closing

An authorized staff member can review the parcel record and official notice with you.
