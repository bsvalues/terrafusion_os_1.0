# Current Use Boundary Quality Spec

## Forbidden Behaviors

The system must not:

- approve classification automatically
- deny classification automatically
- waive penalty automatically
- determine statutory exception automatically
- issue final notices without human review
- mutate Dossier document bodies from Forge
- mutate Atlas geometry from Forge
- mutate Treasurer payment records from Forge
- silently edit TerraTrace events

## Required Visibility

The system must show:

- calculation version
- policy version
- human-review disclaimer on notices
- AI-assist disclaimer if AI is enabled
- simplified-interest warning until production interest engine is complete
