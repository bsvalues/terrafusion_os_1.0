# Tenant Onboarding Runbook

## Step 1 — Create County Tenant

Create county record with:

- county ID
- county name
- policy version
- branding theme

## Step 2 — Enable Core Slices

Enable only:

- coreWorkbench
- rollbackCalculator
- notices
- terraTraceAudit
- policyGovernance

## Step 3 — Load Demo Data

Import:

- classification inventory
- rollback worksheets
- evidence index

## Step 4 — Validate

- run rollback
- generate notice preview
- confirm Trace append
- confirm RBAC
- confirm policy version

## Step 5 — Staff Demo

Run assessor demo validation pack.

## Step 6 — Controlled Pilot

Use real parcels but non-final notices until approval flow validated.
