# Current Use Multi-County Governance

## Purpose

Support multiple assessor offices while preserving:

- county isolation
- county policy versions
- county branding
- county workflow differences
- county deployment pacing

## Rules

- Policy packs are county-scoped.
- Trace events are county-scoped.
- RBAC is county-scoped.
- Imports are county-scoped.
- Feature flags can differ by county.

## Recommended Rollout

1. Internal alpha county.
2. Friendly pilot county.
3. Regional expansion.
4. Cross-state abstraction only after operational proof.
