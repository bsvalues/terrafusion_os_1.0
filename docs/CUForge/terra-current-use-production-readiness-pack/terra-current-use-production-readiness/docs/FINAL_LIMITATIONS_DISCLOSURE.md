# Final Limitations Disclosure

Before pilot, disclose:

1. The system supports assessor judgment; it does not replace it.
2. Rollback calculations must be validated against county-approved data sources.
3. Notices require authorized human approval.
4. AI, if enabled later, is advisory only.
5. GIS automation is not authoritative unless Atlas integration is validated.
6. Treasurer collection remains outside Forge calculation authority.
7. Historical calculations are preserved and corrected through versioned records, not overwritten.
