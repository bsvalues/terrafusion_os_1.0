# Assessor Feedback Checklist

## Operational Fit

- [ ] Lifecycle states make sense.
- [ ] Current Use terminology is familiar.
- [ ] Rollback calculation display is understandable.
- [ ] Evidence checklist matches real staff work.
- [ ] Notice flow feels legally safe.
- [ ] Appeal/reclassification deadlines are useful.
- [ ] Treasurer handoff matches office procedure.

## Risk / Trust

- [ ] Staff can see where numbers came from.
- [ ] Staff can explain calculation to owner.
- [ ] Staff can defend removal decision.
- [ ] Staff can find supporting documents.
- [ ] Staff can see what was sent and when.
- [ ] Staff can tell AI is advisory only.

## Blockers

- [ ] Missing required statute/rule.
- [ ] Missing county-specific procedure.
- [ ] Wrong terminology.
- [ ] Wrong workflow order.
- [ ] Missing notice language.
- [ ] Calculation trust concern.
- [ ] Integration dependency.
