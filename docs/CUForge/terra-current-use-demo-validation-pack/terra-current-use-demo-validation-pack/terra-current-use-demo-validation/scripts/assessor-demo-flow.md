# First Assessor Demo Flow

## Goal

Show that TerraFusion understands Current Use as a lifecycle, not a form.

## Demo Timebox

15–20 minutes.

## Demo Scenario 1 — Farm & Ag Voluntary Withdrawal

1. Open parcel `aaaaaaaa-aaaa-aaaa-aaaa-aaaaaaaaaaaa`.
2. Open Property Workbench.
3. Click Current Use tab.
4. Show classification state: Owner Withdrawal Requested.
5. Show classified acres and homesite exclusion.
6. Run rollback calculation.
7. Point out four-year Farm & Ag rollback rule.
8. Point out penalty suppression.
9. Open calculation explanation ledger.
10. Show policy version.
11. Show TerraTrace event.
12. Show draft notice preview.

## Demo Scenario 2 — Open Space Removal Review

1. Open parcel `cccccccc-cccc-cccc-cccc-cccccccccccc`.
2. Show seven-year rollback.
3. Show removal state.
4. Show appeal/reclassification deadline panel.
5. Show controlled notice issuance gate.

## Demo Scenario 3 — Continuance Evidence Missing

1. Open parcel `dddddddd-dddd-dddd-dddd-dddddddddddd`.
2. Show continuance pending.
3. Show missing owner intent response.
4. Show Dossier evidence packet.
5. Show Dais follow-up task.

## Close

Ask assessor:

- Does this reflect the way your office actually manages Current Use?
- Which screen saves the most time?
- Which calculation or notice risk worries you most?
- What would block this from pilot use?
