# First Assessor Demo Runbook

## Positioning

Do not pitch this as a generic app.

Say:

> This is a Current Use lifecycle command center for assessor staff. It helps track qualification status, evidence, rollback exposure, notices, appeal windows, and audit history in one place.

## What To Emphasize

1. This does not replace staff judgment.
2. This does not automatically approve or remove classification.
3. Every calculation is explainable.
4. Every high-impact action is auditable.
5. Notice issuance requires human approval.
6. Policy versions are preserved.
7. Documents remain in Dossier.
8. GIS remains Atlas-owned.

## Do Not Overclaim

Do not say:

- “It automates Current Use decisions.”
- “It guarantees legal compliance.”
- “It replaces assessor review.”
- “It issues notices automatically.”
- “It fully integrates GIS already.”

## Best Demo Path

1. Current Use tab.
2. Rollback calculation.
3. Explanation ledger.
4. Notice preview.
5. TerraTrace.
6. Evidence packet.
7. Policy version.

## Questions To Ask

- What are you doing in spreadsheets today?
- Which step is most error-prone?
- Who is the office expert for Current Use?
- What notices are hardest to manage?
- What would make a rollback calculation defensible?
- What would need to be verified before trust?
