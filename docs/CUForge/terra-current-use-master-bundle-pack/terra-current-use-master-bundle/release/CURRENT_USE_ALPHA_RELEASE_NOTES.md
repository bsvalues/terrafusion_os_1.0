# Current Use Internal Alpha Release Notes

- Current Use Property Workbench tab

- assessor timeline

- explanation ledger

- AI assist disabled
- Treasurer payment collection disabled
- import migration disabled
- multi-county admin disabled

## Release Rule

Do not promote beyond internal alpha until an assessor validates terminology, workflow order, and calculation explainability.
