# Terra Current Use Master Bundle

This is the master integration layer for the TerraForge Current Use Command Center.

## What Exists

A complete generated package family for:

- frontend Workbench
- backend APIs
- rollback calculations
- statutory interest
- policy governance
- notices
- controlled issuance
- Dossier evidence
- Dais workflow
- Atlas spatial hooks
- Treasurer handoff
- appeals/reclassification
- compliance
- analytics
- import migration
- RBAC
- observability
- E2E testing
- training
- multi-county governance
- canonical data model
- execution control

## What To Build First

Not everything.

Build the first alpha only:

```txt
parcel → Current Use tab → rollback → explanation → notice preview → Trace
```

## Production Discipline

Every expansion slice remains behind feature flags until the core path is stable.
