# Terra Current Use Alpha Merge Kit

This pack turns the generated Current Use slices into a sane first repo merge.

## Goal

Do not merge all generated packs at once.

Merge the first alpha lane only:

```txt
core frontend
backend phase1
rollback tests
policy governance
TerraTrace audit
notice preview
security/RBAC
observability
E2E harness
demo validation
```

## Output

A practical PR plan, file placement map, DI registration map, import-fix guide, and alpha merge checklist.
