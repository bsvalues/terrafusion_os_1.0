# Definition of Done — Current Use Alpha

Alpha is done when:

- Current Use tab renders in Property Workbench
- rollback calculation runs
- Farm & Ag four-year rule tested
- Open Space seven-year rule tested
- explanation ledger visible
- notice preview disclaimer visible
- policy version visible
- trace event visible
- appraiser cannot issue final notice
- health endpoint works
- assessor demo script can be completed

Alpha is not done because all slices exist.

Alpha is done when the smallest operational path works.
