# TerraFusion frontend

Frontend component for TerraFusion government services platform.

## Development
```bash
npm install
npm run dev
```

Generated by TerraFusion Workspace Infrastructure Builder

## OS object catalog & intent contract

- Neutral OS primitives are registered in `frontend/src/terrafusion-os/catalog/osObjects.ts`.
- Each entry exposes an `id`, label metadata, and a React component reference. Consumers should resolve components via `listOSObjects()`/`resolveOSObjectComponent()` instead of importing modules directly to preserve catalog governance.
- Object-level interactions emit the `object_selected` intent with the payload `{ objectId: string }`. The Omni Intent context maps this contract to right-rail panels (Signal Summary, Linked Systems, Timeline & Drift). Any new OS object must emit the same contract to remain domain-neutral.
