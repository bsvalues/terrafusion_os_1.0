## Honest section (read this before you ship)

- **Improvement lane is not fully sealed.** SYNC-COMPLETE-2-V3
  (year-sliced ImprvAttr-S1 stage) is in place and resumable, but the
  full-corpus seal blocked behind an instrumented re-run that has not yet
  completed. The lane works in isolation (proven by SYNC-DOCTRINE-4-V8
  attribute drain) and is safe to operate, but a full ATTR-DRAIN over the
  entire corpus has not been replayed end-to-end since the V3 fix landed.
- **FISMA-HIGH is a posture target, not an accreditation.** See
  [`docs/security/baseline.md`](../security/baseline.md) for the live open-gap
  table. Marketing language has been retracted across the codebase (PR
  [#819](https://github.com/bsvalues/terrafusion_os_1.0/pull/819)). The platform
  is built to FISMA-HIGH controls; a third-party accreditation pass has not
  been performed.
- **Aspirational AI swarm counts have been removed.** Public docs no longer
  claim "1,008 production agents." The AI swarm coordinates real work, but
  the headline number was an inherited marketing figure, not a measured
  production load.

## Operator-action items required post-deploy

1. **Apply 5 EF migrations.** From a host with backend toolchain installed:
   ```bash
   cd backend
   dotnet ef database update --project src/TerraFusion.Data --startup-project src/TerraFusion.API
   ```
   The migration-apply gate (PR-6) will fail CI on the next PR if this step
   was skipped.
2. **Run `scripts/governance/branch-protection.sh`** (already done in the
   PR-5 merge; re-run only if branch protection has drifted).
3. **Verify deployed git SHA:**
   ```bash
   curl -s http://<deploy-host>:5000/health | jq .gitSha
   ```
   The response value MUST match the commit tagged `v1.6.0`. If it returns
   `"unknown"`, the deploy host did not rebuild from `deploy-phase-beta.sh`
   with the new `GIT_SHA` build-arg threading; rebuild before declaring the
   deploy clean.
4. **Take a fresh `pg_dump`** (nightly automation is already wired by PR-4;
   confirm one cycle has run successfully post-deploy).
5. **Acknowledge the honest baseline** — read
   [`docs/security/baseline.md`](../security/baseline.md) before issuing any
   external comms that reference FISMA. Use "FISMA-HIGH posture target"
   phrasing; do NOT claim accreditation.
