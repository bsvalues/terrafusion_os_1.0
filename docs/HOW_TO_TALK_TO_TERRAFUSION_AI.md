## 🚫 **WHAT NOT TO SAY**

### **❌ Avoid These Phrases:**

- "Can you help me with..." (too vague)
- "I'm having trouble with..." (not specific enough)
- "Something is wrong with..." (not actionable)
- "I need assistance with..." (too formal)

### **✅ Say These Instead:**

- "TF: Fix [specific issue]"
- "TF: Deploy [specific component]"
- "TF: Start [specific system]"
- "TF: Create [specific thing]"
