# LEV-135 - District Assistance Worksheets

## Overview

District assistance worksheets are tools provided to taxing districts to
help them understand their levy capacity and prepare accurate levy requests.

## Worksheet Types

### 1. Levy Request Worksheet

Provided to each district before the levy request deadline.

| Field                      | Pre-filled | Description                    |
|----------------------------|-----------|----------------------------------|
| Prior Year Certified Levy  | Yes       | From assessor records            |
| Estimated HLL              | Yes       | Based on preliminary values      |
| New Construction Estimate  | Yes       | From assessor field reports      |
| Banked Capacity Available  | Yes       | Computed from prior year history |
| Requested Levy Amount      | No        | District fills in               |
| Requested Rate             | No        | Computed from amount and AV      |

### 2. Capacity Analysis

Shows the district's historical levy usage relative to its HLL:

- 5-year trend of HLL vs. actual levy
- Cumulative banked capacity
- Projection of future capacity under various growth scenarios

### 3. Election Planning Guide

For districts considering a lid lift or excess levy:

- Current levy rate and remaining capacity
- Estimated rate impact per dollar amount
- Voter approval thresholds and timeline
- Sample ballot language references

## Distribution Timeline

| Date       | Action                                         |
|------------|-------------------------------------------------|
| September  | Worksheets generated with Round 1 values       |
| October    | Updated worksheets with Round 2 values         |
| November   | Final worksheets for levy request submission    |

## Access

Districts access their worksheets via the BCBSLevy portal using
district-specific credentials. Worksheets are read-only except for
the levy request amount field.
