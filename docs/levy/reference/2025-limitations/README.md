# LEV-110 - HLL Worksheet Format and Calculation Methodology

## Overview

The Highest Lawful Levy (HLL) worksheet determines the maximum levy amount
a taxing district may impose under Washington State law (RCW 84.55).

## Worksheet Structure

| Row | Field                        | Description                                  |
|-----|------------------------------|----------------------------------------------|
| 1   | Prior Year Levy Amount       | Certified levy from the preceding year       |
| 2   | Limit Factor                 | Typically 1.01 (1% increase allowance)       |
| 3   | Base Levy                    | Row 1 x Row 2                                |
| 4   | New Construction Value       | AV of new construction added to the roll     |
| 5   | New Construction Levy        | Row 4 x prior year rate                      |
| 6   | Refund Fund Levy             | Optional statutory refund reserve             |
| 7   | Highest Lawful Levy          | Sum of Rows 3 + 5 + 6                        |

## Calculation Steps

1. Start with the prior year certified levy.
2. Apply the 1% statutory increase (or banked capacity, if applicable).
3. Add the levy attributable to new construction.
4. Add any refund fund allowance.
5. Compare to the district's requested amount.
6. The certified levy is the lesser of the HLL and the requested amount.

## Banked Capacity

Districts that levy less than their HLL may "bank" the unused capacity
for future years. Banked capacity accumulates up to the statutory ceiling.
