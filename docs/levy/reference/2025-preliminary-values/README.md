# LEV-116 - Preliminary Values Report Rounds

## Overview

Preliminary assessed values are produced in multiple rounds as the assessor
finalizes the property assessment roll. Each round refines the values used
for levy rate computation.

## Report Rounds

### Round 1 - Initial Estimate (August)

- Based on prior year values plus known revaluations.
- Used by districts for budgeting purposes only.
- Clearly marked "PRELIMINARY - NOT FOR LEVY COMPUTATION".

### Round 2 - Board of Equalization Adjusted (October)

- Reflects changes from Board of Equalization hearings.
- Includes new construction values identified by field appraisers.
- Closer to final but still subject to late appeals.

### Round 3 - Final Preliminary (November)

- Incorporates all known appeals and corrections.
- Used as the basis for levy rate computation.
- Districts submit levy requests based on this round.

### Round 4 - Certified Values (December)

- Final assessed values locked for the tax year.
- No further changes except court-ordered adjustments.
- Levy rates computed and certified against these values.

## Report Contents

Each round includes:

- Total AV by district and property class
- New construction AV by district
- Change from prior round (absolute and percentage)
- Count of parcels by property class

## Distribution

Reports are distributed to taxing districts, the county treasurer, and DOR
via the BCBSLevy portal or as PDF/XLSX exports.
