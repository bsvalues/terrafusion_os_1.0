# Brain reports (generated)

Generated briefs land here — not authored by hand, produced from canon + memory + checks:
- `daily-brief.md` — snapshot of `brain status` for the day
- `release-readiness.md` — rollup of [[../memory/release-gates]] + open P0/P1 drift

Today these are produced ad hoc via the CLI (`pnpm brain status`, `pnpm brain release`). A future
Level-4/5 step can emit them to files on a schedule. Until then this folder documents intent.
