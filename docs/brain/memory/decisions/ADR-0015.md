# ADR-0015 — SEAL Enforces Generated Wiki and Reserved Staging

- **Date:** 2026-06-09 · **Status:** Accepted · **Decision class:** R3 (CI governance enforcement)

## Decision
Wire generated Wiki drift detection and reserved-staging governance into SEAL.

## Reason
The Wiki is now a downstream artifact of Cortex canon and must not drift. Reserved municipal-office
code is forward-staged and gated; regressions must be blocked.

## Scope (Option 2 — no duplication)
SEAL (`seal-gate-fast.yml`, `governance-fast` job) runs:
- `brain wiki --check`
- `brain check reserved-staging`

`write-lanes` remains enforced by `spec-gates.yml` (line 99) and is **not** re-run in SEAL.

## Implementation
Two blocking steps added after the `platform-lint` step (`seal-gate-fast.yml:507,511`):
- **Brain — Wiki freshness (generated from canon)** → `node scripts/brain/brain.mjs wiki --check`
- **Brain — reserved-staging ratchet** → `node scripts/brain/brain.mjs check reserved-staging`

Node-builtin only (no extra install dependency).

## Proof (local CI-equivalent)
- `platform-lint`: 0 violations (workflow edit didn't break Rule 5; seal-gate-fast is already a prGate)
- `brain wiki --check`: exit 0
- `brain check reserved-staging`: exit 0
- `brain check`: all green

**Negative tests (clean, reversible, 2026-06-09):**
1. Inject manual drift into a generated wiki page → `brain wiki --check` exit **1**.
2. Regenerate → exit **0**.
3. Drop a frozen controller from `reserved-staging.json` → `brain check reserved-staging` exit **1**
   (now-unregistered controller flagged).
4. Byte-restore → exit **0**.
5. All checks green again.

Both gates fail-closed.

## Known gap
`governance-fast` is skipped on `docs_only` changes, so a pure-canon edit that forgets to regenerate the
wiki would not be caught by SEAL. Follow-up: a dedicated always-run job (or include `docs/brain/canon` in
classify's NON_DOC set).

## Deferred
- SEAL consolidation of all brain checks (`brain check all`)
- D-002 Dais verification (completed separately as WO-001)
- D-003 drift scans / release evidence

## Effect on CI
Deferred until committed — CI runs committed files; the Brain is currently uncommitted.
