## How to add a row
1. Drift surfaced by a detector ([[findings]]) or by a build/test run.
2. Assign owner = the layer/suite that owns the fix (per [[canon-digest]] write-lanes).
3. Set severity against the 1.0 priority stack in [[release-gates]].
4. Close only with evidence (commit hash, test count, log tail). No "probably fixed."
