explicit, hash-pinned local Atlas projection module through a disposable filesystem-confined Node
process. The foundation advances beyond the completed test-local shadow proof without registering a
runtime consumer or changing persistent runtime selection.

- Hash the source, copy only that module to an invocation-owned directory, hash the copy, and

- Use explicit local Node invocation, filesystem permission confinement, network denial, bounded
  incremental I/O, a timeout no greater than 30 seconds, and process-tree termination.
- Return structured Polygon, Point, unavailable, and fail-closed outcomes.
- Require exact output shape and properties, preserve county and parcel identity, validate geometry,
  normalize accepted output deterministically, and remove every invocation-owned artifact.
