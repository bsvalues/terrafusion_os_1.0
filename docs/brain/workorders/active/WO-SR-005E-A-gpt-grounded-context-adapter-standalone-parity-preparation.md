## Objective

Determine whether committed GPT/RAG source can safely map to
`gpt.grounded-context@1.0.0`, and define exact sovereign and standalone parity scopes without
provider calls, runtime adoption, extraction, protected data, or destination product writes.

## Result

The frozen contract and standalone bootstrap are ready for later parity work, but the current RAG
result is not a safe adapter input. It does not bind each chunk to a stable source identity and does
not carry county, dataset-key, trace, authorization, or denied-result identity. Titles, URLs, list
position, and caller assertions must not be used to invent those values.

WO-SR-005E-A2 is admitted as a docs/evidence-only R2 design node. It must identify a committed
pre-projection source boundary or define a build-fresh, provider-neutral source projection with
exact identity provenance. No adapter, provider, runtime, extraction, workflow, or destination
implementation is authorized.
