## 🏗️ **Module Architecture Standards**

### **Standard Module Structure**
Each module follows consistent government-grade architecture:

```
modules/[module-name]/
├── module.manifest.json     # Module configuration and metadata
├── package.json            # Dependencies and build configuration
├── README.md               # Module-specific documentation
├── src/                    # React/TypeScript frontend
│   ├── components/         # UI components
│   ├── services/          # Business logic services
│   ├── types/             # TypeScript definitions
│   └── utils/             # Utility functions
├── src-tauri/             # Rust backend (if applicable)
│   ├── src/               # Rust source code
│   ├── Cargo.toml         # Rust dependencies
│   └── tauri.conf.json    # Tauri configuration
├── backend-services/      # C# backend services
│   ├── Controllers/       # API controllers
│   ├── Services/          # Business logic
│   ├── Models/            # Data models
│   └── *.csproj          # .NET project file
└── tests/                 # Module-specific tests
```

### **Module Integration Patterns**

#### **Data Flow Architecture**
```
Frontend (React/Tauri) 
    ↓
Backend Services (C#/.NET)
    ↓  
Legacy System Adapters (TerraFusionSync)
    ↓
External Systems (Harris PACS, Tyler, etc.)
```

#### **Communication Patterns**
- **REST API** - Standard HTTP/JSON communication
- **SignalR WebSocket** - Real-time updates and notifications
- **Message Queue** - Asynchronous processing coordination
- **Database Events** - Data change notifications

## 🚀 **Module Management Operations**

### **Development Workflow**
```bash
# Create new module
./scripts/create-module.sh --name=new-module --tier=2

# Register module in system
npm run register-module --module=new-module

# Hot-reload module during development
npm run hot-reload --module=new-module

# Deploy module to production
npm run deploy-module --module=new-module
```

### **Module Health Monitoring**
```bash
# Check all module status
curl http://localhost:5000/api/modules

# Check specific module
curl http://localhost:5000/api/modules/ai-swarm/status

# Refresh module cache
curl -X POST http://localhost:5000/api/modules/refresh
```

### **Module Performance Testing**
```bash
# Run module-specific tests
cd modules/testing-suite && npm test

# Run comprehensive system tests
./scripts/discover-all-tests.sh

# Performance benchmark all modules
npm run benchmark-modules
```
