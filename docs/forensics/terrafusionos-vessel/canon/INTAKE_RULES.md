# TerraFusionOS Intake Rules

No content enters TerraFusionOS except through:
1. Work Order
2. Provenance ledger entry
3. Validation gates

Allowed intake states:
- built-fresh
- promoted contract
- promoted doctrine
- reference-only
- blocked
- deferred

Runtime code requires explicit execution release.

Loop 44 does not authorize runtime code.
WO-CORE-1 remains unreleased.
