## Step 3: Scrub Git History (per repo)

**Important**: Simply deleting files in a new commit does NOT remove them from public history.
Use BFG Repo-Cleaner (faster) or `git filter-repo`.

### Install BFG (one time)
```bash
# Download BFG jar from https://rtyley.github.io/bfg-repo-cleaner/
# Or: brew install bfg (macOS) / choco install bfg-repo-cleaner (Windows)
```

### terra-forge-rebuild
```bash
cd /tmp && git clone --mirror https://github.com/bsvalues/terra-forge-rebuild.git
cd terra-forge-rebuild.git

# Remove .env file
bfg --delete-files .env

# Remove database dumps
bfg --delete-files PropAccessData.zip
bfg --delete-files dbo_2.zip
bfg --delete-files "dbo_2-2.zip"
bfg --delete-files MSSQLBckup.zip
bfg --delete-files benton-county-sales.csv

git reflog expire --expire=now --all && git gc --prune=now --aggressive
git push
```

### TerraMiner
