## 🔧 HOW TO USE THE NEW TOOLS

### **1. Validate Workspace**
```powershell
# Standard validation
.\scripts\validate-workspace.ps1

# Verbose output (show all details)
.\scripts\validate-workspace.ps1 -Verbose

# Quick mode (skip time-consuming tests)
.\scripts\validate-workspace.ps1 -QuickMode
```
**Output**: Detailed report in `VALIDATION_REPORTS/`  
**Shows**: 33 tests, pass/fail/warning status, recommendations

---

### **2. Check System Health**
```powershell
# Standard health check
.\scripts\health-check.ps1

# Detailed process info
.\scripts\health-check.ps1 -Detailed

# Continuous monitoring (refresh every 5s)
.\scripts\health-check.ps1 -Watch
```
**Shows**: System requirements, resources (memory/disk/CPU), services, ports, processes, workspace health

---

### **3. Start Everything (One Command!)**
```powershell
# Start all services
.\scripts\start-everything.ps1

# Install dependencies first, then start
.\scripts\start-everything.ps1 -InstallFirst

# Quick mode (only essential services)
.\scripts\start-everything.ps1 -Quick

# Skip backend (if already running)
.\scripts\start-everything.ps1 -SkipBackend

# Don't start AI Companion
.\scripts\start-everything.ps1 -NoCompanion
```
**Starts**: Backend API (5000), Dashboard (3001), GIS (3002), Demo (3000), AI Companion  
**Time**: 30 seconds (vs 10-15 minutes manual)
