## 🚀 **EXECUTION COMMANDS**

### **Available NPM Scripts**
```bash
# Full system validation
npm run validate:full-system

# Component validation only
npm run validate:components

# Component validation with auto-fix
npm run validate:components:fix

# Critical components only
npm run validate:critical

# Specific component
npm run validate:component Trust_Fabric
```

### **Direct Python Execution**
```bash
# Full validation
python3 validate-everything.py

# With auto-fix enabled
python3 validate-everything.py --fix

# Critical components only
python3 validate-everything.py --critical

# Specific component
python3 validate-everything.py --component Trust_Fabric
```
