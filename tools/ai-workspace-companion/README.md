## 🚀 **QUICK START**

### **1. Install Dependencies**
```bash
cd ai-workspace-companion
npm install
```

### **2. Launch the Companion Agent**
```bash
# Standard launch
npm run companion

# Development mode (verbose)
npm run companion:dev

# Quiet mode (minimal output)
npm run companion:quiet

# Check status
npm run companion:status

# Show help
npm run companion:help
```

### **3. Start Using Your AI Companion**
Once launched, you'll see the interactive prompt:
```
🤖 Terrafusion> 
```

## 🚨 **TROUBLESHOOTING**

### **Common Issues**

#### **Agent Won't Start**
```bash
# Check workspace validation
npm run companion:status

# Verify you're in the correct directory
pwd
# Should show: .../terrafusion_os_1.0

# Check for missing dependencies
npm install
```

#### **TypeScript Compilation Errors**
```bash
# Check TypeScript version
npx tsc --version

# Clean and rebuild
rm -rf dist/
npm run build
```

#### **Permission Issues**
```bash
# Check file permissions
ls -la

# Fix permissions if needed
chmod +x launch-companion.ts
```

### **Debug Mode**
```bash
# Enable debug logging
DEBUG=* npm run companion:dev

# Check agent logs
npm run companion:status
```
