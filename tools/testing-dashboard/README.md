Terrafusion Test Command Center

Quick Start

```bash
node tools/testing-dashboard/server.mjs
# Open http://localhost:4137
```

Notes

- Run Discovery calls ./scripts/discover-all-tests.sh or PowerShell fallback
- Execute All Tests runs latest test-discovery-*/execute-all-tests.sh
- Status reads COMPLETE_TEST_SUMMARY.md for insights
- Set TF_TEST_UI_PORT to change port
